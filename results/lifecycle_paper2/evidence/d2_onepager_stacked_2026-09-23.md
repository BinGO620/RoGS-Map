## 1. 假说的推导（全部来自已有 run 的新读数——R2"新证据"条款依据）

L1c 失败的定量诊断（`verdict_L1c_occupancy.md` §3.3）指出 warm 区基元 α 系统性偏高。
逐机制做不动点分析，得到**精确解释与一个可检验预言**：

| 形态 | 每 KF 更新链 | 不动点 / 行为 |
|---|---|---|
| occupancy 单开（L1c） | EMA 抬升（e≈0 ⇒ α←0.9α+0.1）后衰减（α←0.9α）⇒ **α←0.81α+0.09** | **不动点 ≈ 0.47**——精确解释 warm 区 α 高（0.4-1.0）：两机制互相抵消 |
| gate 单开（L1b） | 抬升被封顶（α 不变），**无下降项** | 钉死 0.22（pt 实测 0.2199）——残影仍按 0.22 渲染 |
| **叠加（本提案）** | gate 挡抬升（α 不变）+ 衰减（α←0.9α）⇒ **α←0.9α 单调棘轮** | 从 0.22 出发：4 个 KF 穿 tau_carve=0.20，10 个 KF ≈ 0.08 |

**完整因果链（prereg_L1b 当初假设、从未被执行过的那条）**：占据期间 α 棘轮下穿 0.20 →
人离开后 `in_front` 打开（背景比残影深）→ **carve 首次点火** → 残影真删除 → fill 补背景。

## 2. 实验设计（判据先锁后才派）

- **臂**：`l1d_person_tracking_stacked`（exit + `evidence_gate: true` + `occupancy_memory: true`，
  纯 config 新文件）× seed 0/1/2 = 3 run；**对照零新增**（L3 exit s0-2 canonical 已有）。
- **主判据**（与 L1b/L1c 同源门槛）：Δ = stacked − exit（freshvac，canonical）；
  **PASS ⟺ ∀3 seeds Δ<0 ∧ |mean Δ| > max(1.19, off_sd)**。
- **约束门**：同 L1b 限值（ATE ≤ +0.5cm 且 ≤ +5%；static PSNR ≥ −0.25dB），逐 seed 报告；
  代价风险声明预锁（gate 单开时 PSNR −1.74dB，叠加可能更狠——如实写，不追加 run）。
- **诊断预测（预锁，不作判据）**：① alpha-ledger a_min 在连续占据段**单调下行穿 0.20**
  （棘轮的直接指纹）；② `alpha_carve_total` 首次 > 0（pt 上从未发生过）；③ 棘轮不应
  触碰 α≥guard 的净静态结构（安全性同 L1c）。
- **击杀分支**：非 3/3 负 ⇒ 补 s3-5 确认（含对照侧，照 L1c 确认批流程）；重判仍不过 ⇒
  **链式假说关闭**，负结果进 §6 边界小节（ DISCIPLINE:363 纪律：不作主张）。
- **off 一致性**：与 exit 的代码面差异 = 零新代码（纯 config 组合，两个 flag 均已
  分别在 L1b/L1c 通过行为面验证）⇒ 免 occoff run，行为面以计数器核对替代。
