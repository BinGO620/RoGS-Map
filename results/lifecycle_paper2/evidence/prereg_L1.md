# L1 预注册：exit/carve 最小效果验证（R7 阶梯第一级）

**落盘时间**：2026-09-20，任何 L1 run 之前 ｜ **上位**：`DECISIONS.md` D2-002（方向）/ D1-002（本级）/ R7（阶梯纪律）

## 1. 唯一要回答的问题

exit/carve（静态侧退场清理）在**论文 2 的序列集（人走动场景）**上有没有**可见**的鬼影清理效果——
还是只在搬箱场景（mvnobox 家族，lifecycle_formal 的主场）有效？**不问其它**（不问 ATE 增益、不问种子方差）。

背景（如实）：lifecycle_formal（27 run、预注册）显示 mvnobox Δ−4.1cm、balloon2 Δ−3.1cm（均 3/3 配对优），
但 **mvnobox2 无效**（1/3 序列，机制激活而 ghost 不降，判决记为适用边界）。L1 的作用之一就是探测
这种失效是否在 Bonn 人走动序列上重演。

## 2. 设计（4 run）

| 项 | 值 |
|---|---|
| 臂 | `off`（无 AlphaLifecycle 块 = 逐位默认）vs `exit`（`AlphaLifecycle: {enabled: true, mode: exit}`） |
| 序列 | **crowd2**（论文 2 集里鬼影最重 4.34cm、动态占比最大 ⇒ 效果可见性最高）+ **balloon2**（生活周期 formal 已证有效的 Bonn 序列 ⇒ 复现对照） |
| seed | 0 |
| 栈 | `combined_prune`（= 论文 1 栈 = 论文 2 baseline；与 lifecycle_formal 同源） |
| 配置 | `configs/experiments/lifecycle_paper2/{crowd2,balloon2}_{off,exit}.yaml`（程序化生成 + 单键差 diff 核验） |

## 3. 判据（跑前锁定）

**主读数（按序列定源，跑前已核）**：
- **balloon2** = `mapping_raw.csv` 的 `static_ghost_excess_depth_l1_cm`（与 lifecycle_formal 同源；负 = 残影更少）；
- **crowd2** = **`render_compare` 离线口径**的 `ghost_excess`（cm，日志汇总行）——已核：
  R33 的 crowd2 运行期无静态评测列（`r33_rebase_baseline_crowd2_seed0/tables/mapping_raw.csv`
  连列名都没有）⇒ 该序列只能离线；两臂同仪器对称（mask 源 auto，两臂一致）。
- **跨序列不比绝对值**（两口径不同），**只在序列内部配对**（exit−off，同 seed 同仪器）。

1. **主（crowd2）**：Δ(exit−off) **为负** 且 **|Δ| > 1.19cm**。
   1.19cm = lifecycle_formal 的 balloon2-off 臂 3-seed sd（同管线噪声参照，保守取值；跨批漂移另有 ~±0.2cm，其 verdict §4）。
2. **复现对照（balloon2）**：Δ 为**负**（先验 −3.1cm）。若 balloon2 都不能复现 ⇒ 先查管线/栈差异，
   **不解读 crowd2**（L1 判读的前提是对照臂成立）。
3. **约束**：ATE 同 seed 配对 ≤ +0.5cm 且 ≤ +5%（A1 口径）；`static_psnr` Δ ≥ −0.25dB。
4. **三件套交付**（R7 契约）：渲染指标表 + 跟踪指标表 + **渲染图 vs 原图对比**（off / exit / GT 三方拼图，
   重点帧放大框；`render_compare.py` 产出 [GT|渲染]，主会话拼三方图）。**缺图不予收口**。

## 4. 分支（跑完必停、看数再走）

- 主判据过 + 对照过 + 约束过 ⇒ **升 L2**（+4 run：balloon、person_tracking2 × {off,exit} × seed0）。
- 主判据不过 ⇒ **补 seed0/1 两条确认性击杀**（+2 run，同设计）⇒ 呈报"机制为搬箱场景特有"的边界，
  论文机制方向回用户重议（D2，一页纸）。**不自动扩批**。
- 对照臂 balloon2 不成立 ⇒ 先诊断管线（不解读主判据）。

## 5. 成本与诚实登记

L1 = 4 run（双卡 ~1.5h）；击杀确认 +2 run；L2 +4 run。**先验风险**：mvnobox2 型失效（机制激活但
ghost 不降）在 Bonn 集重演的概率不低——这正是 L1 用 4 个 run 先问的原因。

## 6. 补遗 1（2026-09-20，L1 四 run 完成、**判据判读之前**登记）

**问题**：§3.1 的噪声带 1.19cm 取自 **lifecycle_formal 运行期仪器**（balloon2 off 跨 seed sd），
而 crowd2 实际用的是**离线 `render_compare` 仪器**（运行期列缺失，§3 已定源）——借带跨仪器，
不严谨。已知离线仪器在 **balloon** 上的**同码重跑抖动 = 1.44cm**（transient_map E↔E2 实测：
render_E 1.7886 vs render_E2 0.351）；而 L1 主判据读数 Δ(crowd2, offline) = **−1.328cm**
（off 1.4657 → exit 0.1378），与 1.44cm 同量级 ⇒ **判读待决**。

**处置（跑前登记，R7 击杀/确认补采样）**：补 **1 个同码重跑** `crowd2_off_rep`（= crowd2_off
逐键相同、仅 save_dir 不同）⇒ 直接测 crowd2 上的离线仪器噪声地板 `|off − off_rep|`。
- 若 `|off − off_rep| < 0.66cm`（< 0.5×1.33）⇒ 主判据按 §3.1 成立（Δ 明确超仪器噪声）⇒ 升 L2；
- 否则 ⇒ 再加 **seed1 的 {off, exit} 配对**（+2 run）要第二个独立配对点；seed1 同向且 |Δ|>0.66cm
  ⇒ 升 L2；否则判 **L1 未过** ⇒ 按 §4 走击杀（补 1 seed 确认后呈报，方向回用户重议）。

**同时如实登记（不参与判据）**：对照序列 balloon2 两仪器方向相反——运行期列 Δ−0.53cm（更好）vs
离线 Δ+0.84cm（更差）；离线在该序列上的绝对值达 −16cm 级（场景结构主导，仪器分辨率差）⇒
**离线 ghost 仅在"小量级场景"（如 crowd2）可用，balloon2 的离线读数不作证据**（运行期列是它的主口径，§3 已定）。

## 7. 补遗 2（2026-09-20，L1 判读遇阻后登记）：3-seed 配对确认（+4 run）

**判读现状（全部程序化 dump）**：
- crowd2（离线仪器）：Δ−1.328cm，但同码重跑噪声地板 2.33cm ⇒ **不可判**（仪器功率不足）；
- balloon2（运行期仪器）：今天 seed0 Δ(ghost)=−0.53cm；**9-06 批同栈同 config 的逐 seed 配对**为
  s0/s1/s2 = −4.79/−3.03/−1.48（3/3 负）⇒ **方向一致性 4/4，幅度 10× 飘**。
- **漂移归因（新发现）**：ghost 代理 = 腾空区 − 非腾空区（背景）；跨批对比显示**背景项漂 5.24cm**
  （20.90→26.14）而**腾空区项稳定**（20.525→20.653）⇒ **该代理跨批不可比、只允许批内配对**；
  9-06 判决的"跨批噪声 ~±0.2cm"表述**被本批证伪**（登记）。
- 约束：ATE/PSNR 全过（crowd2 ±0.025cm、balloon2 −0.062cm；static PSNR 均在 ≥−0.22dB）。

**处置（跑前锁定）**：补 **balloon2 seed1/seed2 × {off, exit} = 4 run**（复用今天 seed0 ⇒ 3-seed 配对；
与 9-06 判据同形）。判据：
1. **3/3 负**（ghost 代理逐 seed 配对全为负）**且 |均值 Δ| > 1.19cm**（同批同仪器跨 seed sd，
   9-06 口径）⇒ **L1 定位判过**（balloon2 这一场景类型成立）⇒ 升 L2（只剩 person_tracking2 一类）；
2. 3/3 负但 |均值| ≤1.19cm ⇒ **弱效应**：如实报告并经用户 D2 定是否值得继续（不进 L2 自动扩批）；
3. 非 3/3 ⇒ 按击杀路径（补 seed 确认后呈报，方向回用户重议）。
**成本**：4 run（~1.5h 双卡）。**同时登记**：本 instruments（运行期 ghost 代理）的跨 seed 幅度不稳，
L3 的数字呈现必须逐 seed 并陈、不做跨批绝对比较。

## 8. 补遗 3（2026-09-20，balloon2 3-seed 未过后登记）：主场确认（mvnobox，6 run）

**balloon2 3-seed 配对结果（程序化 dump）**：Δ = −0.53 / −2.19 / **+0.40** ⇒ **2/3 负、均值 −0.77cm**
（门槛 1.19）⇒ **补遗 2 判据未过**；对照 9-06 同设计为 3/3 负（−4.79/−3.03/−1.48，均值 −3.10）⇒
**同栈同 config 不复现**。支持读数：**腾空区项（跨批稳定分量）6/6 个 seed 一致变差**
（今天 +5.38/+4.89/+2.73；9-06 +6.81/+1.30/+3.26）⇒ 代理的"改善"由漂移的背景项制造。

**处置（R7 击杀补采样：在机制主场上做最终判定）**：**mvnobox**（9-06 最强证据处，Δ−4.1cm、
fill −7.6cm）补 **3 seed × {off, exit} = 6 run**（该序列首次在当前栈跑，无 seed0 可复用）。
判据（与补遗 2 同形）：**3/3 负 且 |均值 Δ| > 1.19cm** ⇒ 机制"限定为搬箱类场景"的边界成立
（paper 不进主线，作为边界素材）；**否则 ⇒ 本族（静态侧 exit/carve 作为论文机制）击杀**，
方向回用户 D2 重议。
**成本**：6 run（mvnobox 短序列，双卡 ~1h）。**登记**：L1 累计已花 10 run（4+1+4+6）。
