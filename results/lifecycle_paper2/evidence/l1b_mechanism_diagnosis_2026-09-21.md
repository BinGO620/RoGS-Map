# L1b 机制路径诊断：gate 生效但 carve 未被解锁（2026-09-21）

**性质**：D1 级诊断（零 GPU，只读 `L1b_person_tracking_gate_s0.consolelog` 的 alpha-ledger 行）。
**触发**：`verdict_L1b_gate.md` §3 —— 主判据 PASS 但 `alpha_carve_total ≈ 0`（0/0/2），
机制路径与预注册假设（"gate 解锁 carve"）不符。本文件给出原因，供 D2 决策。

## 2. 原因：`beta=0.9` 的 EMA + "每帧都被观测为静态" ⇒ α 停在 `tau_carve` 之上

EMA 递推（`utils/alpha_lifecycle.py:ema_alpha_update`）：

```
α_new = β·α_old + (1−β)·(1 − evidence)      β = 0.9
```

- **纯下降情形**（evidence=1，深度不一致）：`α ← 0.9·α`，从 0.2199 起 **1 个 KF** 就跨过 0.20
  （数值验证：0.2199 → 0.1979）。⇒ 下降通路本身**没有障碍**。
- **实测却恒定 0.2199** ⇒ 这些基元**每个 KF 都被判为静态**（`evidence ≈ 0`）：
  `α_EMA = 0.9·0.2199 + 0.1·1 = 0.2979`（想升回 0.298）→ **gate 把它压回 0.2199**。
- 于是形成**动态平衡**：EMA 每次想抬升、gate 每次压回 ⇒ α **冻结在 0.2199**，
  **恰好停在 `tau_carve = 0.20` 之上 0.02**，carve 合取门（`α < 0.20`）**结构性不可达**。

**这不是实装缺陷**（gate 按规格工作：只减不升），而是**参数共振**：
`tau_carve = 0.20` 落在"β=0.9 EMA + 每帧静态证据"这条不动点轨迹的可达范围**之上**。
`verdict_L3.md` §9 的诊断（exit 臂 α 钉在 0.2445）与此**同源**——gate 把钉住位置从
0.2445 下移到 0.2199，**但没有跨过阈值**。

## 3. 对"主判据 PASS 从哪来"的含义

- **不是通过 carve**（carve=0）⇒ 改善来自 gate 对 α 的**持续压制本身**：
  α 更低的基元在后续 KF 的渲染/深度权重、复位（`a_lt_reset` 从 1 → 361 明显抬升）、
  以及致密化-剪枝路径上行为不同 ⇒ 间接影响残影读数。
- 预注册 §6 的诊断预测（"掩码内 α 不回升"）与**全局聚合量**方向一致（a_min 确实被压在
  0.2199 不升），但**掩码内的行为未被直接观测**（终态 PLY 不含 static_prob；per-KF 日志
  只有聚合量）⇒ 与 `verdict_L1b_gate.md` §3 一致，登记为**间接支持、未直接验证**，不声称
  "在数值上被证实"；且它没有兑现为 carve——预测的**中介环节**（α<0.20 ⇒ 删除）缺失。
