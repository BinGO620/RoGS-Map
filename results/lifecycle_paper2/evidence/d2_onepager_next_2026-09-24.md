# D2-009 一页纸：方法下一步三选一（呈用户拍板；2026-09-24）

> **性质**：D2 立项呈报。依据 = Phase 0 两份新工件（`ghost_census_2026-09-24.md`、
> `mask_path_audit_2026-09-24.md`）。**注意：Phase 0 推翻了本计划立项时的隐含前提**
> （原设想"用 ρ 存在权重场做软删除"），照实改向——这正是一次零 GPU 测量该起的作用。

## 1. 发生了什么（平实语言）

我们花了五批实验（L1b/c/d/e + param）想删掉人走过留下的残影。普查（首次直接测残影
总体本身，4 个已有 run）给出三个决定性数字：

1. **残影总体 α 中位数 = 1.0**（几乎全不透明）——五批实验的门（0.20/0.25/0.35）瞄的是
   一个只占 19% 的少数群体。**设计对象与实测对象不是同一批基元。**
2. **把"该删的目标"（深带 Δz>0.05）整批抹掉，区域误差从 +1.8 恶化到 +9.9cm**——
   它们是撑住那块区域的几何；**删除本身是破坏性的**（这就是 crowd3 反向损伤的量化解释）。
3. **不是漏进来的人内容**：基元颜色更贴背景（离人色 0.42-0.47 / 离背景 0.13-0.18），
   且插图/建图/deferred 三处硬决策点代码审计全部掩码合规。

⇒ 人走后的走廊区域误差是**"整片区域的估计质量"问题**（占据期被掩码挡出观测，离开后
重新收敛；新鲜段 3.5cm 差于 settled 段 1.8-3.2cm），**没有一个"错误子群"可供删除**。
⇒ 五批实验的失败是结构性的（杠杆用错了层），不是调参不够。**判据层已无赢面。**

## 2. 选项（每个含一句话代价 + 一句话收益 + 我的预期效果上限）

| 选项 | 做什么 | 代价 | 收益与天花板（诚实） |
|---|---|---|---|
| **A. 观测债补偿**（推荐先做） | 用掩码历史算每区域的"观测债 D(x)"（占据期被挡出 loss/插图的帧数）；离开后把优化迭代/关键帧回访/致密化优先级按 D(x) 分配（纯资源分配，不加门、不加状态） | 实装 2-3 天；L1f 3 run ≈40min | 直接攻"新鲜→settled"缺口；对所有用掩码的序列通用；**上限 ≈ 缺口本身 1-2cm（pt）**，但机制干净、ATE 风险低 |
| **B. 责任场联合估计**（数学层） | 每基元存在 log-odds ℓᵢ，渲染用 ρᵢ=σ(ℓᵢ)；掩码降级为**软证据项**而非硬排除；删除变成梯度驱动的边缘化——三处硬决策统一消解为一个估计问题 | 实装 4-5 天（动渲染合成+优化器）；L1f ≈40min | 理论上最干净（无门/无阈值/掩码 FP-FN 免疫）；**但 Phase 0 不预测 pt 有大幅增益**（残影非基元病理）；新可学状态有扰动 ATE 的风险 |
| **C. 换域泛化**（保守但实） | 承认"几何信息充分处有效"（balloon2 −20cm 量级、box −1.7~−2.0）；把这套已验证机制推广到 **TUM f3_wk（人动态基准）**+ 更多序列；pt 进边界小节（机理链现已最完整） | 掩码适配 0.5-1 天 + L2 批 ≈2h GPU | 收益在**量级**上（不是 1-2cm 而是 2-20cm）；风险=部分序列可能无效应；**直接回应用户"要处理人"**（TUM 就是人） |

## 3. 默认建议与理由

**默认 A→B（先 A 后 B）**，理由：A 是唯一直接对应实测缺口、且不引入新失败模式的改动
（2-3 天、低风险），它的结果会告诉我们"欠观测补偿"能拿回多少；B 是数学层重构，作为
A 的后续（若 A 有效则 B 可能放大；若 A 无效则 B 的先验也应下调）。
**若你的优先级是"必须在人上有量级效果"→ 选 C**：因为 Phase 0 的结论是"Bonn-pt 的人
残影本来就只有 1.8-3.5cm、且被 ±4cm 的 seed 散布淹没"，而 TUM-walking 的场景几何
与相机轨迹都不同，残影量级可能完全不同——**先花 1 天在 TUM 上做同款普查**（这次普查
已证明很便宜），用数据决定是打 A/B 还是打 C。

**我的倾向明说**：先做 **TUM 普查（1 天，含掩码适配）**，再在"有量级信号的地方"投入
A 或 B。因为 Phase 0 教给我们的最重要一课就是：**先测目标总体，再设计机制**——
我们前面五批全栽在没做这件事上。
