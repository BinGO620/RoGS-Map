# prereg_instrument_v2 — 仪器 v2：matched-control freshvac 三参照 + 全臂重评分

> **性质**：判据先锁（先于任何实装/跑批）。**依据**：用户 2026-09-24 交接建议（拍板①）+
> R3 保守默认（呈报未答 ⇒ 最保守可逆项）。**零训练**：只重渲染不重训。
> **本 prereg 冻结的只是判据与口径**；实装脚本、样本对拍数字、重评分结果另文件记录。

## 1. 假设（一句话）

现有 freshvac 系列仪器在 pt/crowd 族上的"残影超额"读数混入参照区构型偏差
（效应量与偏差同阶 1-3cm ⇒ 符号随参照翻转，night_report §3b/§3c）；用三参照
matched-control 口径（v2）重评全部已有臂，可把"C1 三支柱效应"与"仪器偏差"分离。

## 2. v2 口径定义（先锁）

三参照逐帧并行计算，全部输出 **median + IQR**（禁均值单独作结论，NOTES:516 规则）：

1. **全域静态**：GT 有效 ∧ 非动态 ∧ 非 vacated（现状保留，官方 freshvac 口径）。
2. **邻域环**：vacated 膨胀 31×31 椭圆核（≈15px 半径）∧ ¬5px 核膨胀 ∧ 静态
   （现状保留，census 现行实现）。
3. **新增·深度-距离匹配对照（第三对照）**：每帧从静态区选取与 vacated 区
   **GT 深度可比**且避开边缘的像素：
   - 深度源 = **GT 深度**（非渲染深度——被评对象不得自证）；
   - 中心 = 该帧 vacated 区 GT 淋度中位数（无 vacated 支撑的帧不计该帧）；
   - 匹配带 = 中心 × (1 ± 0.15)（±15%；依据：宽于缝隙带判别 5-10cm 的相对口径，
     且与掠射角深度分辨率同量级——**样本对拍后可按 §3 程序收窄，不许放宽**）；
   - 排除：动态 ∧ vacated ∧ 距图像边缘 < 15px（与邻域环外半径一致）∧ GT 无效；
   - 支撑下限：匹配对照像素 ≥ 200 px/帧，低于则该帧标记 `m3_under_supported`
     并在汇总中单列（不计入通过帧数）。
   - **采样上限**：帧内超过 5000 px 时随机下采样到 5000（固定种子 0，可复现）。

指标 = 每参照的 `vacated_vs_ref_depth_l1_cm`（同 census/render_compare 现行
depth-L1 公式，逐帧）。**v2 主读数 = median over 帧的 Δ = 臂 − off**（配对，同帧集）。

## 2b. 范围（先锁）

全部已有臂的 canonical 终态 run（派发前 `ls` 实数并写死清单于执行件）：
L1 / L1b / L1c / L1d / L1e（seam+param）/ L2-gate / L3（含 TUM off/exit）。
**TUM 例外**：night_report §3 已判 TUM 普查仪器不稳（vac 覆盖 7-25 万 px/帧），
TUM run 的 v2 三参照**照算并如实落表**，但判读以官方 render_compare 口径为准
（v2 对 TUM 仅作"仪器不稳证实/证伪"的对照材料，不作判效依据）。

## 3. 匹配带对拍程序（先锁；先于全臂批）

对 2 个样本 run（pt off s0 + balloon2 off s0）：若匹配带 ±15% 下支撑像素
中位 < 200 px/帧 ⇒ 按序尝试 ±25%、±35% 收窄失败序列，取第一个满足下限的带宽；
若全失败 ⇒ 该序列匹配对照判不可用，如实登记，v2 退化为双参照 + 不可用原因。
**只许收窄方向失败时放宽，不许从 ±15% 起步放宽**（防"调到出信号"）。

## 4. 判读判据（先锁）

对每支柱（同帧集配对，v2 三参照各自独立判读）：

- **C1 支柱存活**（balloon2 / mvnobox / crowd3）：v2 三参照下 Δ = exit − off
  的 median 全部同号（负 = exit 改善）且 |median| ≥ 0.5cm。
- **pt 超额性质判定**：pt off−exit 在 v2 下若三参照符号一致 ⇒ 报该符号与量级；
  符号不一致 ⇒ 结论 = "效应量 < 仪器分辨力"，pt 侧 1-2cm 级效应不可判
  （**预期结果：这正是 §3b 的翻转被 v2 证实**）。
- **TUM**：不判效，只落表。

## 5. 不改变历史判决的承诺（先锁）

v2 = **诊断级仪器重读**。历史 `verdict_*.md` **原文零改动**（仅允许头部加带日期
指针块，D1-004 先例）；本 prereg 产出 = 一页表 + 判读文件，**不产生新机制判决、
不触发任何族的重开/关闭**（那需要新 prereg + 新证据）。若 C1 在 v2 下消失
（三参照不再同号），呈报用户（D2），不自动改叙事。

## 6. 双溯源与交付

verdict/一页表头部记：测量代码 sha（instrument_v2 脚本 commit）+ 分析代码 sha
（判读脚本 commit）。交付三件：① v2 重评分 JSON（per-run per-frame 三参照）；
② 一页表 `instrument_v2_onepager_table.md`（程序化生成，禁手抄数字）；
③ verdict_instrument_v2.md（关卡① slam-critic 先于落盘）。

## 7. 边界

- 本 prereg **不预注册任何机制**（A/B/C 不在此列，判据层冻结不新增门/阈值）。
- 判据层禁止新增门/阈值/合取——v2 的 200px 下限与 5000px 上限是**仪器参数**
  （支撑可判性），不是判效阈值，二者性质已在此声明区分。
- 时间盒：样本对拍当轮完成；全臂重评分 ≈1 天；超时如实登记部分完成。

## 8. 实施澄清（2026-09-24 追记；**不改判据，只登记实现与原文的差异**）

关卡①（slam-critic，Reject 一轮）指出的实现/措辞偏差，逐条登记如下（判据 §4 与 §2 主读数定义**不变**）：

1. **§2 "深度-距离匹配"实现 = 深度分层匹配**：实现只含"GT 深度落入 vac 区 GT 深度中位数 ±带"
   + "距图像边缘 ≥15px"，**无独立的空间距离项**（`utils/instrument_v2_core.py`）；名称中的"距离"
   指深度距离。表中标签已改"深度分层匹配(m3)"。
2. **§2 "固定种子 0"语义**：`GEN = np.random.RandomState(0)` 为模块级共享流，跨帧顺序抽样
   （可复现，但**不是**"每帧用种子 0 重开"）。
3. **§2 "m3_under_supported 帧标记与单列"未实装**：改为在输出中落盘各参照**可用帧数**
   （§1c 明细）与**支撑像素中位数**（`support_px_median`），并以"任一参照可用帧 < 50% 共同帧"
   作为可判性判据（⚠稀薄）——覆盖原条款意图，但字段名与原文不同。
4. **§2 采样上限 5000 仅作用于 m3**（vac 未采样）⇒ 两区样本量不对称，属仪器局限，已记 README §5。
5. **§4 判据子集**：prereg 原文列 balloon2 / mvnobox / crowd3（9 对）；表内另列 balloon / mvnobox2
   为**扩展**（非判据），已在表中显式标注"扩展"。
6. **聚合口径修正**：§2 "median over 帧的 Δ" 按**逐帧配对 Δ 再取中位**实现（首版误为"各臂帧中位数相减"，
   已改正为 5695bc94）；两种读法的差异实例见 README。
7. **IQR** 已按 §2 落表（§1c 明细列）。

## 9. 修正案 1（2026-09-24，关卡① 整改后登记）—— 可判性判据（thin / ⚠稀薄）

**性质声明**：§7 只禁"新增判效门/阈值/合取"。本项是**可判性**判据（"该参照区是否存在、
读数是否有足够帧支撑"），不是效应量阈值；但**它会改变达标计数**，故按修正案登记、
两读法并陈，并连同本仪器结论一并呈报（D2）。

**唯一定义**（`scripts/02_analysis/instrument_v2_judge.py:thin_pair`）：
- 分母 = 该对**两臂共同帧数**（与 §1c "帧数"栏同源）。**注意**：§1b 表的"共同帧数"
  是"三参照同时可用"的帧数，**不是**本判据的分母（二义已消除）。
- 分子 = 该参照在两臂皆有效的帧数。
- 判定（任一成立即 ⚠稀薄 ⇒ **判效不可用**，不计入达标）：
  ① 任一参照 分子 < 50% 分母；② 任一臂的 support 像素中位为 0。

**两读法并陈（C1，prereg §4 子集 9 对）**：
| 读法 | 达标 | 明细 |
|---|---|---|
| **含 thin（本表主读数）** | **2/9** | balloon2 s1/s2（均 exit 改善）；crowd3 3 对不可判；mvnobox 3 对同号未达 0.5 |
| 不含 thin（对照） | 4/9 | 另含 crowd3 s0（**方向为 exit 变差** +2.09/+1.88/+5.27）与 crowd3 s1；两者均 ⚠稀薄（可用帧 6–8/17）|

**依据**：crowd 族 `past`（历史掩码并集）覆盖 ≈66–100% 视野 ⇒ 对照区在多数帧上不存在
（support 中位 0，可用帧 2–8/17）；在"多数帧无对照"的读数上判效 = prereg §5 要防止的
"在偏差 ≥ 效应 的指标上打空拳"同类错误。

**判据正文（§2/§4）未改**；本修正案只登记可判性与聚合口径的实现细节。
