## 1. 决定性的三个数字

| 量 | 实测（pt off s0 / exit s0 / exit s1） | 含义 |
|---|---|---|
| 覆盖腾空区的基元 **α 中位数** | **0.9998 / 1.0 / 1.0** | 残影总体**几乎全不透明**；α<0.25 的只占 19%（4333/22661） |
| **抹掉深带（Δz>0.05）群体**后的超额 | +3.19→**+7.45**（off）/ +1.79→**+9.92**（exit s0） | **这些基元是承重的**：删掉让腾空区误差**恶化 4-8cm** |
| 抹掉缝隙带（0.05-0.10）后的超额 | 3.19→2.88（off）/ 1.79→1.41（exit） | 缝隙带群体只占超额 ~10-20% |

## 2. 结论（每条带工件键）

1. **五批实验的 α 门全部瞄错人群**：残影总体的 α 中位数 = 1.0（42% 在 0.95-1.0）。
   L1b 封顶（α>0.22 的抬升）、L1c 衰减（α<0.35）、L1d 棘轮、L1e 缝隙 τ=0.25——
   设计对象是"已被怀疑的低 α 基元"，而实测总体是**地图最自信的那批几何**。
   （工件：`census_*.json` 的 `SEAM_alpha_hist` / `vac_alpha_hist`。）
2. **删除目标集不是误差来源，且删除是破坏性的**：抹掉深带群体使腾空区深度误差从
   +1.8 恶化到 +9.9cm（exit s0）。这量化解释了 crowd3 的反向损伤（Δfv +1.56）
   与 L1b/L1e 的零转化：**carve 要删的正是撑住那块区域的几何**。
3. **不是漏入的人内容**（H-A 否）：基元色离人色中位 0.42-0.47、离像素观测色 0.13-0.18
   ——颜色更贴背景。代码审计同向：插图/建图/deferred 三处硬决策点全部掩码合规
   （见 `mask_path_audit_2026-09-24.md`）。
4. **走廊误差是"整片区域估计质量"问题，且新鲜段最差**：官方 freshvac（30 KF 窗）
   pt off 3.50 / exit 3.41cm，而本普查全历史走廊口径 off 3.19 / exit 1.79cm
   ——**新鲜腾空段比已 settled 段差**，lifecycle 的收益只出现在 settled 口径。
   即：人被掩码挡出的那块区域在离开瞬间处于"欠观测"状态，随时间被后续观测收敛。
5. balloon2 对照（方法确实有效的场景）：SEAM α 中位同为 1.0，但超额量级 −20cm
   （腾空区远好于背景），抹掉深带仅从 −20.3 → −16.5 —— **同一把刀在两个场景的
   处境完全不同**，成功不来自"删得准"，来自"退场物留下的坑有观测填得上"。

## 3. 方法学注记（如实）

- 口径差异：本普查用**全历史掩码并集**的腾空区（比官方 freshvac 的 30 帧窗更宽）；
  两者都报（§2.4）。fresh-window 分支在本脚本里对 idx≥347 的帧返回空（bug 未修，
  该分支不作为证据——§2.4 的 fresh 数字取自官方 render_compare 仪器）。
- Δz 是**基元中心**的投影差，不是渲染深度差；α 为 sigmoid 激活后的 PLY 不透明度。
- 4 run：pt off s0 / exit s0 / s1 / balloon2 exit s0；每 run 17 帧（canonical 帧集）。
- 复现：`PYTHONPATH=. python scripts/02_analysis/ghost_population_census.py --run-dir <run> --frames <frames> --out <json>`；
  注意 CVD 只认序号（`CUDA_VISIBLE_DEVICES=1` 时 `--device cuda:0`）。

## 4. 对机制设计的直接含义（供 D2-009 一页纸）

- **判据层已死**：不可删（承重）、可删的（低 α 少数）不是误差源、α 阈值全体错靶。
  ⇒ 任何"再换一个门/阈值/合取"的设计都没有赢面（与用户对细粒度改进的批评一致）。
- **正确的杠杆在估计层**：走廊区域在占据期被掩码挡出 loss 与插图（审计已证），
  离开后处于欠观测；误差 diff 且随时间收敛。⇒ 框架级动作 = 对**被掩码挡出的区域**
  做非对称的估计资源补偿（再观测/再优化/再致密化优先级），并让"存在与否"由损失
  梯度仲裁（存在权重场 ρ）而非阈值判定。
