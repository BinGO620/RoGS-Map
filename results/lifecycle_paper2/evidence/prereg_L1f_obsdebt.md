# prereg_L1f_obsdebt — 观测债补偿（A，含容量定向变体）L1f 判据（先锁）

> **性质**：判据先锁（先于任何实装/跑批）。**依据**：D2-011 ②（用户拍板 A 含容量定向）+
> **B0 边界 PASS 的强约束**（`b0_headroom_verdict_2026-09-24.md` §4——判据门槛 ≥1.48cm、
> 跨 seed 聚合读法、balloon2 主域、pt 只作约束门）。**硬顶**：L1f 判决 10-02 前出炉。
> 实装 default-off；单测两态；关卡① 先于派发。

## 1. 假设（一句话）

腾空区在"被掩码占据期"被挡出优化（观测债 D(x)），离开后该区域重建质量差于持续观测区；
**按 D(x) 把优化迭代 / 关键帧回访 / 致密化·fill 插入优先级分配给高债区域**（纯资源分配，
无新门/阈值/状态），可降低腾空区残影超额，且 ATE 不劣化。

## 2. 臂与成本（R7 L1 级）

| 臂 | 定义 | run 数 |
|---|---|---|
| 主臂 obsdebt | exit_fill 管线 + 债驱动资源分配（D(x) = 该像素被动态掩码覆盖而未获渲染监督的帧数；分配律：① fill 插入配额按债降序重分配 ② 高债区插入基元额外局部迭代步，独立 Adam） | balloon2 × 3 seed + person_tracking × 3 seed = 6 |
| 对照 exit_fill（**修订 2026-09-24，关卡① 重大-1**） | **同为 exit_fill 管线、obsdebt=False**（单变量对照：唯一差异 = 债分配律） | **补 3 run（balloon2 s0-2）**——原"对照 = 已有 L3 exit 纯删"与主臂管线不同，作废 |
| 对照 off | 不动 | 沿用（ATE/PSNR 基准） |

预计新增 GPU ≈ 9 run × 13min ≈ 2h（双卡 1h）。

**主判据 Δ = obsdebt − exit_fill（同管线单变量）**；exit（纯删）与 off 的读数并陈作参考。

## 2b. 点火计数的机械定义（**关卡① 重大-4 补**；零点火 = run 无效不进判决）

点火 = 以下任一事件在 consolelog 中出现非零计数：
1. `obsdebt KF .* total=` 行的 total 字段随 KF 递增（账本在增长）；
2. `obsdebt-fill KF .* kept=` 行存在且 kept>0（预算重分配实际发生）；
3. `obsdebt-boost KF .* extra_steps=[1-9]`（迭代配额实际发生）。
判据机以正则提取三项计数落 JSON；三项全零 ⇒ 记 `FIRING=none`，run 无效。
**已知风险（如实）**：历史 balloon2 vacated 事件 max=122 px ≪ 预算 2000 ⇒ 分支②可能
预期不触发——此时判效仅依赖分支①③ 的点火；若 ①③ 也零点火 ⇒ 本批记"零点火"，机制族
按 prereg §3 击杀分支处理（不追加 run）。

## 3. 主判据（先锁；B0 约束条款 1/2 全部落入）

- **主效果域 = balloon2**（可判域）；**pt 族只作 ATE/PSNR 约束门 + 机制点火计数（诊断）**。
- **读法 = 跨 seed 聚合**：3 seed 配对 Δ（obsdebt − exit）逐帧配对后取 **median-of-medians**，
  报 IQR；**禁止单 seed 逐帧读数作判**（B0：IQR 3–7cm）。
- **PASS** =（balloon2 上）三 seed Δ 的 median-of-medians **< −1.48cm**（= 2× 分辨力，
  B0 判据门槛；负 = obsdebt 改善）**且** ≥2/3 seed 同号（负）。
- **击杀分支（预锁）**：PASS=False ⇒ 补 3 run 确认批（第 2 seed 组 s3-5）⇒ 6-seed 重判仍
  FAIL ⇒ **观测债族按 R2 永久关闭**（不再做参数变体；容量定向形态一并关闭）。
- **指标**：instrument_v2 三参照（m3 深度分层匹配为主读数参照；全域静态/邻域环并陈）+
  per-frame median/IQR（`judge_reread_median` 同读法）。

## 4. 约束门 + 误删护栏（先锁）

- **ATE 非劣化**：obsdebt 相对 off 的 ΔATE ≤ +5%，且逐 seed 无 >+10% 单点（与 L3 同门）。
  **披露（关卡① 重大-3）**：balloon2 对照区 col8 ATE ≈ 5.36cm（已超 5cm 红线区）⇒ +5% 门
  实际容差仅 ≈0.27cm——本批在**噪声受限区**内判约束门，约束门结果只作"非劣化/不判"两读，
  不作"劣化"结论。
- **静态 PSNR 非劣化**：canon 口径 Δ ≥ −0.65dB（D1-014 M6 修订界）。
- **机制点火计数**：债驱动的致密化/fill 插入事件数 > 0（否则 = 未点火，run 无效不进判决，
  记"零点火"诊断）。
- **护栏**：static_coverage ≥ 0.99（L1e 同款）；破 = run 无效。
- **预算上限**：基元数膨胀 ≤ +80%（对照 exit 现状 +12~72% 的容差；如实落表）。

## 5. 不改变历史判决的承诺（先锁）

L1f 是新机制族（A）的第一个 L1；**不重开任何已关闭族**（观测债 ≠ 缝隙带救援 ≠ 参数变体——
B0 已把"关闭边界"写明：失败则族整体关闭）。历史 verdict 原文零改动。
