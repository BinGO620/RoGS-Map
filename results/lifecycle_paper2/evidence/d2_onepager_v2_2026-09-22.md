## 2. 用户既定方向核对

"人群族仍是要解决的问题"——三种口径一致显示人群族无 exit 效应，方向**不变**；
L1b gate 是该方向下首个可复制正效应，但带代价、机制路径未证实。本页选项都在回答：
**人群族的下一个 GPU 小时花在哪。**

## 3. 选项（勾一个；未答复按 R3 执行默认建议 A）

| 选项 | 内容 | 成本（一句） | 收益（一句） |
|---|---|---|---|
| **A（默认建议）** | **L2 泛化批 + box 亚族阶段性表述**：gate 效应泛化到 pt2/crowd/crowd2（R7 L2 原文规格 = +3 个不同类型序列 × 1 seed，与既有 exit 臂同 seed 配对；exit 臂 canonical 渲染已存在，只需 3 个 gate run + 3 个渲染；判据先锁 prereg，晋级门 = ≥2/3 序列显效应）；论文框架同步把 exit/carve 主张阶段性收窄到 box 亚族（措辞限定人物轨迹区） | ≈1h 远程 3090 + 一份 prereg（若锁定判据需要多种子配对结构再扩 seed，增量另计） | 人群族 gate 方向的去留得到判决性数据；论文主张落到有效仪器支撑上 |
| B | **机制参数修复再试**：tau_carve 0.20→0.25（或 β 0.9→0.5）解锁 carve + 重测（诊断文件 §4 B1） | 新 prereg + ≈4 run ≈ 1h GPU；**附呈 R2 定性问题**（见下注） | 可能消除 PSNR 代价、机制故事闭环（carve 活过来） |

**选项 B 的附呈问题（须与 B 一并拍板）**：R2 每族仅一次机会。L1b 主判据 **PASS**（家族
未止损）⇒ B 到底算"族内第二次机会"（若失败 ⇒ 人群族**永久关闭**）还是"新机制族变体"
（失败不关门）？系统无法自裁，升级 D2。
**注（不属三选项）**：box/balloon 非人物移动者覆盖（GT 位姿补偿残差流方案）是把 box 主张
从"人物轨迹区"升格为"全移动者"的共同前提（≈0.5–1 天工具建设，任何选项下都可并行，且
自带独立验证设计：用人物序列做验证集）。

## 4. 默认建议 A 的理由

1. **R7 阶梯合规**：L1（pt 单序列 4 run）已过主判据 ⇒ 法定下一步就是 L2 泛化；跳过 L2
   先修机制 = 在不知道效应是否可复制的情况下改参数——若效应本不泛化，B 修好了 carve
   也无处可验。
2. **A 的数据是 B/C 共同的基础设施**：无论之后走 B 还是写论文，"gate 效应在人群族是否
   可复制"都是必需读数。
3. **代价 profile 只有跨序列数据能定价**：ATE 越门是单 seed 推动、PSNR 三 seed 一致——
   哪个是普遍代价直接决定 gate 能否进论文，这正是 L2 批要回答的。
4. C 与既定方向相悖故不默认；B 把方向问题换成机制问题，且捆绑家族关闭风险。

## 5. 反悔成本（每选项一句）

- **A**：GPU 时间沉没；L2 不过 ⇒ 人群族 gate 方向击杀（信息非浪费），box 亚族表述不受
  牵连；撤销 = 停批，零额外成本。
- **B**：若定性为族内 R2 机会且失败 ⇒ 人群族**永久关闭**（不可逆）；若定性为新机制族 ⇒
  撤销 = 弃参数回 A/C，损失 ≈1h GPU + 一天 prereg。另：T3 已降"待复核"，旧评估
  "硬删有 T3 前科风险"本身待复核（B 不涉硬删，影响仅限于未来若提 B2）。
- **C**：零花费；撤销 = 日后重启实验，成本 = 时间；风险 = 人群族叙事空窗对投稿时间线的影响。
