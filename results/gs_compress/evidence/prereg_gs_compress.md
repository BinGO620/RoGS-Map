## 0. 一句话

把 SLAM 生长出来的**动态场景 3DGS 地图**做**离线分区感知压缩**（有损量化 codec），
以**自有点**（① 按静态/残影区分账的比特分配；② 尺寸感知剪枝的有损操作点）构成
CVM 可投的**正向效率机制贡献**——**不动动态内容、不新增优化期可学标量、不进在线逐帧预算**。

## 1. 为什么这条路不被已证的两堵墙挡住（正当性，先锁）

| 已证的墙 | 内容 | 本线为何不撞 |
|---|---|---|
| **墙 A：α 通道共线**（D2-017，数学） | 任何 **per-primitive 可学标量**必经 `α_eff`，与既有通道共线 | codec 是**编码层**：对**已有属性**重编码 + 码本索引，**不新增优化期 per-primitive 标量**，且**离线跑在已冻结地图上**（无优化回路）⇒ 不经 α_eff。**隔离条款**：码本/量化表**绝不回灌优化器**（只在编码-解码间用）；若未来把码本训练进优化，须先体检共线（九轴扫描 §3.3 已登记此推断债） |
| **墙 B：在线成本 + 静态门**（D1-020/D1-021；mope +13.84%） | 逐帧在线开销无界、静态受损 | 纯**离线后处理**：不进 tracking/mapping 逐帧预算 ⇒ 无在线成本主张，M3 型配对计时**不适用**。静态侧反而**可测**：压缩引入的失真在分区指标上显影（§4） |

**与"最终地图口径"的关系（口径先锁，承 E2 教训）**：本线的渲染/分区指标**只与同地图的未压缩渲染对照**
（同一 PLY 的 `render_compare` 基线），**不与 run 时 eval、不与 R33 表、不与任何跨批数字混引**。
压缩 = 同地图的率失真曲线，控制变量是码率，不是 SLAM 配置。

## 3. 机制（移植件 + 自有点；组装式 D2-018③）

离线 codec 管线，输入 = 存档最终地图 PLY；输出 = 压缩码流 + 重建 PLY（喂 `render_compare`）。

| 件 | 内容 | 身份 |
|---|---|---|
| **坐标编码** | 场景包围盒 → 均匀标量量化（bit-depth 扫描）或八叉树；xyz 是字节大头 | 移植件（3DGS 压缩标准做法） |
| **属性量化** | `f_dc`（SH-DC 三通道）标量量化/VQ；`opacity`（logit 域）标量量化；`scale`（log 域）标量量化；`rot` **归一化后**3 分量量化（去掉冗余第 4 分量 —— 本会话实测 PLY 里 rot 未归一化，norm∈[0.53,2.10]） | 移植件 |
| **熵编码** | rANS / zlib；报 bytes 与 bits/primitive | 移植件 |
| **自有点 A：分区感知比特分配** ⭐ | 用本仓静态/残影分区（canonical 掩码 + `static_eval` 口径）把基元分类为"静态区支撑 / 残影区支撑"；对残影支撑基元**降比特 / 提高截断**——**同总码率下**改变比特在动/静区的分布 | **自有点（与 CGS-SLAM/DiskChunGS 均静态场景的核心差异）** |
| **自有点 B：尺寸感知剪枝** | 离线剪除"大而有限"的巨基元族（运行期无尺度护栏，`gaussian_model.py:467-470,982` 只剔 Inf/NaN）——作为率失真曲线的**有损端操作点** | **自有点（连接 crowd 族基元膨胀实证）** |

**开关与默认**：codec 是**独立脚本**（非 config 段）⇒ 零污染主代码、零"默认关逐位一致"义务。
**明确不做**：不碰 SLAM 主代码/config；不做在线压缩（不在建图循环内编码）；不新增任何 per-primitive
可学标量；不做 4D/时间维；不重开已死族；不主张"首个动态场景 GS 压缩"（须先回源核对文献，见 §7）。

## 4. 判据（数值先锁；判据机程序化产出，禁手抄）

### 4.0 口径（先锁，禁混引）
- **基线 = 同地图未压缩渲染**（同一 PLY 走 `render_compare`，`--interval` 固定，与压缩重建逐帧同网格）。
- 全部渲染读数报 **mean + 逐帧 + IQR**；分区读数（static/ghost）与全图并陈。
- **rate** 报 `bits/primitive` 与 `total_bytes_ratio`（压缩后/原始）**双口径**；不得只报其一。
- **ATE 按构造不变**：本线不产生新轨迹；仅做**重载渲染一致性 sanity**（重建 PLY 能被 `load_ply`+`render` 无错消费、n_prims 守恒除非剪枝臂）。

### 4.1 L1（3 地图；机制可达性门，R7 的 2–4 单元阶梯）

| # | 判据 | 通过线 | 逻辑 |
|---|---|---|---|
| **C1 codec 跑通（存在门）** | 编码→解码→重建 PLY→渲染 全链无错；bytes/bits 落盘 | 跑通 | 前置件；不是效果的证据 |
| **C2 率失真** | 全图 PSNR 损失 vs rate 的曲线（每图 ≥3 个码率点） | **须先标定**（见下） | 绝对线**不得先验拍数**（mope M1 教训）：先在 1 图（balloon）上标定 codec 工作点，再锁多图判据 |
| **C3 分区分配净增益** ⭐ **CCF-C 门** | **同总码率下**，分区感知分配 vs 均匀分配：残影区指标（`ghost_excess_depth_l1_cm` / `ghost_excess_psnr_db`）的改善 | **> 0 且超噪声带**（相对门，**无需魔数**） | = mope A2"净增益 vs R0"的压缩线对应物；**这是 CCF-C 正向贡献的判据**：不是"少伤"而是"同码率下分区更好" |
| **C4 静态不劣化** | 同总码率下，分区分配的 `static_psnr` Δ vs 均匀分配 | ≥ **−0.3 dB**（界，标定后复核） | 防"残影变好靠牺牲静态" |
| **C5 记账字段剥离** | 只保 14 个渲染字段（丢 6 记账字段 + rot 归一化）的**无损可重建性** | 渲染输出与全字段版**逐位近似一致**（容差=浮点） | 证明 30% 死重可无损去除——**accounting 证据**（不作独立贡献，作支撑） |
| **C6 生效门** | 码率/比特账/重建 PLY 落盘；分区掩码 provenance 落盘 | 落盘 | 保可复算 |

### 4.2 L2（主表；效果门）
**规模先锁**：**baseline + gate 两臂 × Bonn 7 序列 × 3 seed = 42 张地图**；每图 ≥5 个码率点。
**主判**：C3（分区分配净增益）在 **跨图/跨 seed** 上**方向一致**（中位 > 0 且 IQR 不跨 0）；
外加 **C2 率失真曲线族**达到标定后锁定的工作点。
**泛化（L3）**：全 84 图 + R34 held-out 面板（TUM 6 序列）复现 C3 方向。

### 4.3 出口规则（先锁）
- **C1∧C2(标定线)∧C3∧C4∧C5∧C6 ⇒ GO**；
- **GO ∧ C3 净增益稳健（跨图方向一致）⇒ 投 CVM（CCF-C）**——分区感知分配 = 正向机制贡献；
- **GO 但 C3 净增益仅边际/不稳 ⇒ claim 收窄**：贡献改立"**动态场景 SLAM 地图的量化 codec + 记账字段剥离 + 膨胀 accounting**"（仍是正向效率机制），分区分配降为**消融件**（仍如实报 R-D 优势或劣势）——**仍可投 CVM**（用户批准的计划 §检查点①）；
- **¬C2 或 C3 为负且不可收窄 ⇒ 止损**：转 EI（B 线，素材现成）。
- **检查点①（10-12，R8-4 呈报用户）**：给 L2 主表达标判定与 GO/收窄/止损结论。

## 5. 反作弊 / 控制（先锁）
- **同码率比较**：C3/C4 的分配对照必须在**匹配总字节**下比（容许 ±2% 码率，超出则该点作废）。
- **掩码固定**：全部用 canonical 冻结掩码；不同掩码源的读数不混算。
- **不作弊的对照**：均匀分配臂 = 同一 codec、同一量化器、只关分区加权（单变量）。
- **禁口径挪用**：不得把"重建 PLY 渲染 vs GT"的绝对 PSNR 当作"压缩增益"；增益一律是**相对同地图未压缩**。
- **时间/成本**：本线无在线成本主张；报 codec 墙钟（CPU）仅作工程报告，不进判据。

## 6. 与既有件的关系（不撞车、不混算）
- **R33/R34 表**：本线**不改**任何既有数字；压缩表是**新增**的独立表（新文件、新的对照轴=码率）。
- **分区协议（paper2 §4）**：本线**复用**它为**测量仪器**（用户五点裁定：不得作贡献主张）⇒ 只作 C3/C4 的读数面。
- **causal 仪器**：本线是离线后处理，**不需要**因果快照（mope 的 A1/V3/A2 并陈规则不适用——本线无在线效应）。
- **mope_layer**：已关 A 线（D2-024 丙）；本线与其**无交集**（mope 是机制层、本线是编码层），只并陈不作对照。

## 7. 贡献框定（组装式；D2-018③）

## 10. 修正案 v1.1：新自有点 = 重尾感知范围量化（乙线，2026-10-04 锁）

> **背景（用户检查点① 选「乙」）**：原 8 类自有点（分区/重要度/water-filling/轨迹可见性/Morton+delta/
> iso-scale/体素合并/位置分配）**均无同码率帕累托优势**（L1 判读 §4/§6.4）。本修正案换轴：
> 从"**分配哪些基元多少比特**"换到"**量化范围本身**"——二者正交，且范围轴**从未试过**。
> **S0 依据（先于本修正案，零 GPU）**：`tail_census_2026-10-04.md` 实测——codec v1 用全局 min/max
> 范围，SLAM 地图重尾把范围撑大：**scale 组 1.36–2.15×、f_dc ≤2.10×、rot3 ≤2.00×、xyz 1.25–1.53×**
> （14 图全覆盖）；尾部成员 = **巨基元**（`s_max(tail)` ≈ −1.6~−3.2 vs 非尾 ≈ −4.3~−5.2，log 域 ⇒ 尾基元大 ~10×）
> 且近全不透明（opa≈0.99–0.9999）⇒ 与运行期无尺度护栏（`gaussian_model.py:982` 只剔 Inf/NaN）一致。
> opacity 组 infl≈1.0（无可压空间）⇒ 杠杆在其余四组。

### 10.1 机制（自有点 C：tail-aware robust-range quantization）
- **范围**：每属性组量化范围由 `[min, max]` 改为 `[p_q, p_{100−q}]`（稳健百分位，q 先锁见 §10.4）。
- **外溢通道（escape）**：落在稳健范围外的基元，索引 + 边界残差另存（成本计入 rate），
  保证"尾部丢真信息"这一富矿**可控**；关掉 escape 即 clip 变体（对照臂）。
- **same-rate 假设（可伪证）**：**同位宽下**，稳健范围对 ~99.9% 基元步长变细（步长比 = 1/infl）
  ⇒ 全图 PSNR 上升；尾部损失若可忽略 ⇒ **同码率帕累托**。**若尾部损失不可忽略 ⇒ 非帕累托，判负**。
- **隔离（承 §1）**：纯编码层，**不新增优化期 per-primitive 标量**、**不回灌优化器** ⇒ 不撞墙 A。

### 10.2 判据（先锁，数值机写禁手抄）
| # | 判据 | 通过线 | 逻辑 |
|---|---|---|---|
| **R1 存在门** | robust-range(+escape) 编→解→重建 PLY→渲染 全链无错；escape 逐位可重建 | 跑通 | 前置件 |
| **R2 同码率帕累托** ⭐ | 匹配总码率（±2%）下，v2(robust+escape) vs v1(min/max) 的全图 PSNR Δ | **> 0 且超噪声带**；且 **static Δ ≥ −0.3 dB**（承 C4） | 正向机制判据（对应 mope A2 的净增益） |
| **R3 尾部无损性** | escape 后尾部基元重建误差 | ≈ 0（浮点） | 证明 R2 的增益不是"丢尾部换来的假象" |
| **R4 clip 变体（描述）** | v2 无 escape（纯 clip）的 ΔPSNR / Δrate | 描述性，不作判据 | 界定"尾部到底值多少比特" |
| **R5 生效门** | range 参数/q/escape 字节账 provenance 落盘 | 落盘 | 可复算 |

**噪声带定义**：同图同帧集下 `render_compare` 是**确定的**⇒ 取 v1 与"v1 重编码同一码流"的 ΔPSNR 作控制（应 ≈0）。

  （"SLAM 地图尾部承重、不可丢"——这本身是有价值的事实），**回退甲**，不追加 run。
