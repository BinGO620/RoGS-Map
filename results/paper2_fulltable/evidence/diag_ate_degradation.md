# 诊断裁决：R33 ATE 劣化归因 —— **(b) 现有信号空间内机制固有**（2026-09-19）

> **预注册**：`diag_ate_degradation_prereg.md`（H1–H4 + 判定规则跑前锁定）。本裁决按其 §3 规则给出分支判定。
> **数据**：`diag_ate_degradation.json`（84 个 consolelog 的只读提取；本文件所有数字键可在其中回查）。
> **性质**：纯重分析，零 GPU；非论文数字，但**结论将进入论文 2 的口径决策与 Discussion**。

## 0. 判定（按预注册规则）

规则要求：单一信号变换（masked-mean 代理）把"门开 ⇔ SWBA 有益"的序列级一致率提到 **≥6/7** 才判 (a)。
实测：**现行信号 4/7，masked 代理 3/7**（代理反而更差）⇒ **判 (b)**。
但 (b) 的内容比"修不了"更有用——见 §4 的三个可写进论文的事实。

## 1. 归因分解（3-seed 均值；逐 seed 已核稳定性）

| 效应 | 定义 | 读数 |
|---|---|---|
| **E_SWBA**（swbaonly−base） | SWBA 本身的效应 | pt1 **−2.69**（大赚）；balloon **+0.97**、crowd2 **+1.83**、crowd3 **+0.95**、pt2 **+1.43**（伤害）；balloon2 −0.12、crowd +0.11（中性）。**伤害/收益逐 seed 全部同号**（pt2：+1.44/+2.17/+0.68；balloon：+0.76/+1.16/+0.98）⇒ 机制性，非噪声（DISCIPLINE #11 的判别标准） |
| **E_LC**（final−swbaonly） | 回环的叠加效应 | 均值幅度全部 ≤0.56 且**逐 seed 不稳**（pt2：−0.09/+0.66/+1.10）；pt2 上 LC verify 全 REJECT（34 条，0 ACCEPT）⇒ 最省读法是**噪声级**，不作机制归因 |
| **E_gate**（gate−final） | R26 门（`swba_max_static_conf=0.38`，final 与 gate 的**唯一**差异） | **无一序列稳定受害**；救回 crowd2 **−1.55**、crowd3 **−0.62**、pt2（2/3 seed −1.28/−1.18） |

## 2. H1–H4 逐条处置

- **H1（信号口径错配）——证伪，且证伪方式有信息量**。masked 代理一致率 3/7 < 现行 4/7。
  关键读数：balloon 的 dyn_frac 仅 **0.128**、pt 家族仅 **0.088**——低 static_conf **不是**被动态区拖低的
  （代理修正量只有 +0.03~+0.05）；**静态区本身的置信度就低**（"tracker 挣扎"是真的），
  但 SWBA 修了更糟。代理只在 crowd 家族（dyn 0.25–0.28）起作用，而那里现行信号本来就能关上门。
- **H2（修正量无方向信息）——成立（弱证据）**。|dt| med 幸存行均值：pt1 0.945 vs pt2 0.959 vs balloon 0.913
  ——同量级、与效益方向无关。**弱证据声明**：consolelog 行宽截断，每 run 仅 ~19 条幸存行（早 KF 偏置）。
- **H3（窗口数非主因）——证伪**。KF 数：pt1 115 / pt2 113 / balloon 87 / crowd3 170（被救回）；与效益方向无相关。
- **H4（pt2 通道）——修正为"全部是 SWBA"**。E_SWBA 逐 seed 同号为正（+0.68~+2.17）；E_LC 逐 seed 不稳
  （且 verify 全 REJECT）⇒ LC 项按噪声处理；E_gate 2/3 seed 救回。

## 3. 核心发现：pt1 与 pt2 在现有信号空间**不可分**（"孪生对照"）

| 量（gate 臂，3-seed） | pt1 | pt2 |
|---|---|---|
| E_SWBA | **−2.69（大赚）** | **+1.43（受害）** |
| static_conf 均值（逐 seed 范围） | 0.300–0.304 | 0.294–0.302 |
| 掩码占比 dyn_frac | 0.088 | 0.088 |
| 门 skip 比 | 0.092 | 0.106 |
| SWBA 实际运行次数 | 103.7 | 100.0 |
| \|dt\| med（幸存行） | 0.945 | 0.959 |
| KF 数 | 115.3 | 113.0 |
| baseline ATE | 11.31 | 10.40 |

⇒ **现有信号维度（帧级可靠性、掩码占比、门开闭、修正量、KF 数）无一区分"挣扎且可修"（pt1）与
"挣扎但不可修"（pt2）**。balloon/balloon2 是第二对近似孪生（conf 0.329/0.358，E_SWBA +0.97/−0.12）。
补充：SWBA 已有的多层防护里，R28 方向相干性 cap 在 R33 已生效，R25 内层门（`swba_min_rel_improve`，
默认 0=off）在本批**未启用**（全部 84 个 log 内层 skip 行数为 0）。

## 4. 对论文 2 的含义（可直接进正文的三个事实）

1. **靶向收益是机制性的**：pt1 −2.7cm（**逐 seed 一致**，三个 seed 区间不重叠）——headline 的真实形态。
2. **可靠性门是一个诚实的"安全层"故事**：R26 门**从未让任何序列稳定受害**，把 ungated SWBA 的伤害
   （crowd2 +1.83 → +0.24；crowd3 +0.95 → +0.30）转成中性——这就是"同一可靠性信号既门控跟踪证据、
   又管理机制副作用"的具体实证，正是文献空位的那个组合。
3. **剩余间隙是已量化的开放问题**（Discussion 素材）：帧级信号分不开"可修的挣扎"与"不可修的挣扎"，
   全批净效应 ≈ 0（21 个配对点均值 −0.09cm）。修它需要**在线反馈型信号**（如"SWBA 修正是否真的
   改善了随后跟踪"），属机制研究 = 论文 3 / 毕业论文的 reliability-aware 主线，不是 config。
4.（口径）过 5cm 线的序列集合 {balloon, crowd, crowd2, crowd3} 四臂不变；绝对 ATE 上 pt1/pt2/balloon2
   两臂均 >5cm。

## 5. 裁决与下一步

- **判定：(b)——不做"修法复跑"**（预注册规则的门槛未达到，且孪生对照显示现有信号空间无单一变换可用）。
  省下的 GPU 窗口直接给论文。
- **论文 2 跟踪节按 §4 的三事实写**（靶向 + 安全层 + 已量化开放问题），建图侧/协议为论文主线（用户已定）。
- **留给论文 3 / 毕业论文**：反馈型 SWBA 门（用"修正后的短时程跟踪改善"作为门信号）——本诊断的
  孪生对照就是它的动机段。
- **遗留（不阻塞，如实登记）**：① E_LC 在 pt2 的 +0.56 逐 seed 不稳且 verify 全 REJECT，其机制来源未定位；
  ② |dt| 统计受行宽截断偏置；③ masked 代理是下界构造，不是真实掩码内均值。
