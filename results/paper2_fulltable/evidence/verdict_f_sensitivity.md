## 三、判读（只写事实）

1. **易序列单调：SWBA 运行越多越差**（crowd2 2.17→2.99、crowd3 1.62→2.23）。
   **本裁决最稳健的一条**：0.30 与 0.45 两臂**同批**（r30 批），其
   `0.30→0.45` 步长 crowd2 **+37.8%**、crowd3 **+37.9%**、balloon **+16.8%**，
   **全部远超各自批间噪声地板**（14.6% / 1.2% / 8.7%），且逐 seed 区间不重叠。
   确认 SWBA 对易序列是净害，门控的作用是**抑制**它。
   （限定：`balloon` 的 `0.38→0.45` 一步仅 +2.7%，落在其 8.7% 地板内，
   故 balloon 只支撑"两端有别"，不支撑"0.38 与 0.45 有别"。）
2. **pt1：0.38 是均值最优工作点，但不是逐 seed 稳健的"甜点"**（2026-09-16 改口）。
   均值 8.86 / **8.06** / 8.46 ⇒ 0.38 最小；逐 seed 与 0.30
   {8.569, 8.827, 9.178} 不重叠，但**与 0.45 {7.726, 8.539, 9.126} 重叠**
   （0.45 有一个 seed 7.726 优于 r32 全部 seed）；且两个差距
   （vs 0.30 = 9.0%、vs 0.45 = 4.7%）**都低于 pt1 的批间噪声地板 12.5%**。
   原表述"pt1 非单调：0.38 是甜点"降格为此。
3. **单阈值无法同时满足两侧**：易序列要 0.30（运行 6–7%），pt 要 0.38
   （运行 87–90%）——期望运行率相差一个数量级，任何单一阈值都是折中。
4. **定性保证在 0.30–0.45 全区间成立**：易序列全部 ≤5cm（balloon2 的
   >5cm 是 baseline 既有、与门控无关），pt1 相对 baseline 的降幅保留
   **21.7–29.7%**（按 R33 同批 baseline 11.3097；0.30: 21.7% / 0.38: 29.7% / 0.45: 25.2%）。
   **口径注意**：若用旧批 baseline（13.6162）则区间为 34.9–42.5%——**该 baseline 已被 R33
   取代**（置换检验 p=0.30 ⇒ 旧批是偏高抽样）。故本条的"增益保留"应读作 **~22–30%**，
   且该百分比跨三个批次（baseline R33 / 0.30,0.45 r30 / 0.38 R32），对照 §4.6 的批结构注记。
5. **根因（诊断，非结论性机制命名）**：门控阈值作用在**绝对值**上，而
   static_conf 分布跨序列不齐——balloon 中位 **0.335**（易序列却低），
   crowd2 中位 **0.412**（易序列却高）；pt1 中位 0.313、crowd3 中位 0.391。
   同一阈值 0.38 在 balloon 放行 79–84%、在 crowd2 只放行 31–34%。
   **static_conf 的绝对水平不构成跨序列的难度度量**，故门控在不同序列上
   做的不是同一件事。
   （**2026-09-15 复核修正**：原写 balloon 0.343 / crowd2 0.432——实测
   逐 seed 中位 balloon 0.329/0.337/0.339（pooled 0.335）、crowd2
   0.4155/0.408/0.4135（pooled 0.412），取自 `SWBA gate kf=` 行的
   static_conf（该行逐 KF 记录，n=261/534）；原值偏高的方向不影响定性。）
6. **无信号的三条序列（2026-09-16 补记）**：`crowd`（2.153–2.653）、
   `balloon2`（5.088–5.628）、`pt2`（10.755–13.451）**各臂逐 seed 区间
   跨臂完全重叠**，本裁决不对其作任何方向性主张；pt2 尤甚（同臂内 seed 极差
   可达 1.95cm）。**不得**用其均值差做论据。
7. **版本效应与运行噪声不可分离（2026-09-16 补记）**：`gatefix_*`（09-09）
   与本批 r32（09-15）**同 config 同 seed 同代码**，仅批次不同，pt1/pt2 的
   差值为 **0.18–0.62cm** —— 与本次归因给"雅可比修复"的 r29→r32 漂移
   （−0.03~+0.86cm）**同量级且区间重叠**。故本重基线的正当性表述为
   "0.38 列确需在当前代码重测（已做）"，**不是**"版本效应被量化复现"。

## 四、结论与处置

- **K8 的原假设（"增益不依赖阈值精确值"）不成立**——存在真实敏感度。
  但**定性保证（易序列 ≤5cm + pt1 增益保留）跨 0.30–0.45 稳健**，故
  敏感度是"工作点沿权衡曲线移动"，不是"方法失效"。
- **论文表述改为如实版**：报告敏感度曲线 + 声明定性保证的稳健区间 +
  0.38 的定位（pt1 优先端）+ 标定来源（仅 pt1/crowd2）。
- **不启动修复**：principled 修复需换机制（自校验式 SWBA，见下），
  属新研究周期；当前主张在现有形态下成立。
- **局限**：~~0.30/0.45 仅 2 seed~~ **已消除**——seed2 于 2026-09-15 补齐
  （14 run，14/14 rc=0），三臂均 n=3，敏感度表平衡。

### 四之二、重基线后的补记（2026-09-16，R32）

- **敏感度主张降格为"噪声受限"**：本表各臂间的差（0.05–0.62cm）与
  **同码同 config 同 seed 的运行散度（0.18–0.62cm，`gatefix` 09-09 vs
  r32 09-15 实测）同量级**。可站住的只剩两条：①易序列单调——由
  **同批**的 `0.30→0.45` 支撑（+16.8~37.9%，远超地板且逐 seed 分离）；
  ②定性保证（易序列 ≤5cm、pt1 降幅 40.8%）。
- **pt1「0.38 甜点」已改口**（见 §三.2）：只在均值层成立，两个差距都在
  12.5% 地板内，且与 0.45 逐 seed 重叠。
- **`crowd`/`balloon2`/`pt2` 无信号**（跨臂逐 seed 全重叠），不得引其均值差。
- 详见 `verdict_f_rebase.md`（含关卡①复核整改记录与下游更新清单）。
