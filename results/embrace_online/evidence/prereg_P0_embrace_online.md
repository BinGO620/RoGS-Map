## 0. 一句话

在**冻结地图**上（零训练、不改 `slam.py`/`utils/`/`gaussian_splatting/` 核心），用探针层仿真
"在线生命周期地图"的因果形态：**逐帧插入（stride=1）+ 滚动窗连续优化 + 生灭由损失梯度裁定
（存在量 ρ + 稀疏先验）**，检验它能否吃掉历史最好因果臂两倍以上的动态区改善
（主判 **M_bad PSNR Δ ≥ +2.5 dB**，≈ 同批 oracle 臂的 25%）。

## 1. 背景与被检假设

- 天花板（已量化，勿重测）：oracle 同图 M_bad PSNR **+10.73/+10.98 dB**、深度误差减半、代价
  6.4%/4.2% 基元（`results/embrace_dyn/evidence/paper2_boundary_note.md` §2）；
  历史最好**因果**臂 = P2c（保持），M_bad PSNR Δ ≈ +1.5 dB 量级；四轮瓶颈归因：**Δt 一阶**
  （dt≥3 保留率 0.01–0.04）、掩码质量一阶、拟合预算非因子、基元 ×5.13 只换 3%（同件 §3）。
- P0 三路改进对应归因的前两项 + 生命周期必需性（P4"插一次即冻结"≈抹掉）：
  ① **逐帧插入**（不再只在 KF ⇒ 直接压 Δt）；② **滚动窗连续优化**（替代单帧 300 步一次性）；
  ③ **ρ 梯度退役**（替代"无退役 ⇒ 静态区被陈旧基元弄坏 −0.53~−2.89 dB"的病根）。
- **被检假设 H1**：三路联合后，因果臂在 M_bad 上的 PSNR 改善 ≥ 历史最好因果臂的 2 倍
  （绝对值 +2.5 dB），且静态区不破房式界、成本 ≤15%。

| 臂 | 定义 | 角色 |

### 3.1 P0o 机制细节（数值全部先锁）

1. **走帧**：j = t0 .. (max(eval)−1)，stride=1，严格只用 ≤ j 的帧。
2. **逐帧插入**：对帧 j 的 canonical 掩码反投影（`unproj_stride=3`，与历史同）；
   **体素去重**（voxel 0.02 m：仅插入缓冲未占据的体素）后追加新基元，ρ 初值 = logit(0.9)；
   新基元属性初始化复用 `make_dynamic`。
3. **滚动窗连续优化**：每走一帧，对缓冲做 **S=10** 步 Adam；每步从**滚动窗 W=4**（最近的 ≤4 帧，
   轮转取样）取一帧计算损失。损失 = **全帧**（有效像素）RGB L1 + 0.1 × 全帧深度 L1(m)
   **+ λ_ρ × mean(σ(ρ))**，λ_ρ = 0.01。
   - **全帧损失是"生灭由损失梯度裁定"的实现本体**：人所在处静态地图解释不了 ⇒ 梯度支持新基元
     （生）；人离开处动态基元与 GT 冲突 ⇒ 梯度压其 ρ（灭）；**无任何显式删除条件/阈值**。
   - lr 沿用历史 `{xyz 5e-4, scale 5e-3, rot 1e-3, opa 5e-2, dc 5e-3}`；ρ 用 opa 同档 5e-2。
4. **ρ 退役（软）**：退役 = σ(ρ)→0 的连续过程，无硬阈值；渲染按现有 α 合成（ρ 乘入不透明度）。
5. **工程护栏（非机制、预声明）**：缓冲基元硬顶 **60k**；触顶时逐出 σ(ρ) 最低者并计数。
   触顶次数进判决（若频繁触顶 = 机制未控住成本，属发现非隐藏）。
6. **生效验证日志**（DISCIPLINE #9）：逐走帧落 `{inserted, evicted, buf_size, mean σ(ρ)}`；
   判决机汇总。**零插入或零退役变化 ⇒ 机制未生效，主判读数按"组件未生效"归因，不得判 PASS。**

### 3.2 预算（先锁）

- P1/P2 沿用既有路径；P0o/P0n/C-o 三条走帧 ≈ 11k 次渲染/图，四图合计预计 **≤2 GPU·h**
  （硬顶 4 GPU·h，超时按 §6 止损处理，不加卡不加时长）。
- 本地 2060 只作实现冒烟（截断帧集）；**正式读数一律远程 3090**（派发前 nvidia-smi，主人任务绝对优先）。

## 4. 判据（数值先锁；判据机程序化产出，禁手抄）

逐图（gate/baseline 各自）报 **median + IQR**（逐帧配对，因果可评帧集上）；两参照并陈 =
M_bad PSNR 与 M_bad depth-L1 同时报（比较前提+测量口径：禁单参照 mean 结论）。

| # | 判据 | 通过线（先锁） |
|---|---|---|
| **J1 主判** | pt2 两图 M_bad PSNR median Δ(P0o−P1) | **各图 ≥ +2.5 dB** |
| **J2 几何参照** | 各图 M_bad depth-L1 比值 median (P0o/P1) | pt2 两图 **< 1.0**（方向与 J1 一致） |
| **J3 静态门** | 各图 static PSNR median Δ(P0o−P1) | pt2 两图 **≥ −0.65 dB** |
| **J4 成本登记线** | n_dyn_max / n_static | pt2 两图 ≤ **15%** ⇒ 过；**>15% ⇒ 不自动 FAIL，但最高出口降为"边界"** |
| **J5 泛化** | balloon 两图 M_bad PSNR median Δ(P0o−P1) | **> 0** 且方向与 pt2 一致（n=3 帧不设 +2.5 线，主域/泛化分工同历史四轮） |
| **J6 可判性** | 各图因果可评帧中 M_bad 支撑 <50% 或 M_bad 像素中位 = 0 | 触发 ⇒ 记"**不可判**"（不是 FAIL），该图退出判据 |
| **J7 阴性对照** | C-o 的 J1 读数 | **必须 < +2.5 dB** 且其 depth-L1 比值 median ≥ 1.15；若 C-o "通过"主判 ⇒ **仪器无效，整批作废** |
| **J8 机制生效** | §3.1 第 6 条日志 | 插入 >0 且 ρ 分布有实际变化（σ(ρ) 中位数随走帧下降或逐出 >0）；否则按"组件未生效"归因 |

**出口判定（先锁）**：
- **PASS** = J1 ∧ J2 ∧ J3 ∧ J4(≤15%) ∧ J5 ∧ J7(对照 FAIL) ∧ J6(可判) ∧ J8(生效)
  ⇒ Phase E 出口 1（呈报 P1 在线 demo，代码保护例外流程全链）。
- **边界** = J1 median Δ ∈ [+1.0, +2.5) dB（pt2 两图）或仅一图达 +2.5，且 J3/J8 过
  （40–80% 判据、机制诉求明确）⇒ 出口 2（一次 R2 修正式快筛，判据不变）。
  J4 超限而指标全过者最高只能到本出口。
- **FAIL** = 其余（含 J8 未生效、J6 不可判、时间盒到点）⇒ 出口 3（停批呈报：乙 单独 L1 或
  丙 纯边界写作，二选一，不做参数变体）。

## 5. 统计与口径红线

1. 全部判据读数 = **median + IQR**（逐帧），禁单值 mean 结论（测量口径 #1）。
2. pt2 与 balloon 的 dB 不得并列相减；gate 与 baseline 两图是"臂间鲁棒性"不是独立复现
   （`paper2_boundary_note.md` §4.2）；**主判要求两图各自过线** ⇒ 图间不做平均。
3. 与历史四轮（GTMC 仪器）数字**只并陈、不混算**（§2 掩码源行）。
4. 帧集 = §2 锁定集合，不得事后增删；冷启动帧不进因果判据但在工件中保留记录。
5. 判据机 = 程序化（`scripts/embrace_dyn/` 内 judge 脚本直接消费探针 JSON 产出
   `online_judgments` 节），判决书引用键名；手写数字 = 违纪。
