## 0. 一句话

**完整算子相对朴素插入的增量 = 静态保护 + 层规模有界，而非动态区增益**。同口径下（传感器
深度 / MaskRCNN 掩码 / 同 KF 日程 / 同 fit / samepose）朴素插入（无生命周期 / 无 S5）动态区
指标反而更好（J1 6.92–9.36 vs R1 5.49–8.95；J2 0.18–0.28 vs 0.23–0.55），但**静态区崩毁**
（J3 **−11.7 ~ −16.7 dB** vs R1 全部落在 ±0.25 内）且动态层**无界膨胀**（28.8万–125.8万基元
vs R1 峰值 0.6万–1.3万）。⇒ **生命周期 + S5 是把离线修复从"不可用"变成"可用"的机制本体**，
§7 的主张按此改述（见 §5）。

## 2. 判读（对照先锁判据）

- **C1（算子增量于动态区）= False（3/3）**：朴素插入在动态区全面更好（J1 高 0.8–2.0 dB、
  J2 低 0.04–0.29）。**预期之中**——朴素无静态保护、无生命周期约束，可全力拟合动态区。
- **C3（S5/生命周期保护静态）= True（3/3）**：朴素 J3 深负 −11.7 ~ −16.7 dB（全破 ±0.25），
  R1 全部落在带内。**生命周期 + S5 的作用是静态保护与层有界，不是动态区增益。**
- **归因链（三层）**：L1_v4 已证「生命周期开 + S5 关」crowd2 J3 = −4.36（`crowd2_s5off`）；
  本对照证「生命周期关 + S5 关」J3 = −15.93 ⇒ **S5 是静态保护的主要杠杆**（−4.36 → −15.93
  的差距即生命周期缺失的贡献），两层缺一不可。
- **代价面（C2）**：朴素动态层无界膨胀（1.26M vs R1 峰值 10k ≈ **125×**）；生命周期（Cond2
  寿命删 + cap）把层规模压在万级，这是 4D 层 codec 与落盘成本的前提。

## 3. 对论文 §7 的含义（叙事改述，诚实分层）

§7 不得再暗示"算子 = 最大化动态区增益"。改述为：
**离线修复的价值 = 在静态零损伤与层有界的前提下取得实质动态区增益**；朴素对照证明
① 无管理的插入会崩毁静态区（J3 −16 dB）② 无生命周期的层无界膨胀 125×；
③ 完整算子的 21/21 是在这两个约束下的成立。§6 的 oracle 天花板（GT 深度 +17.9–22.2 dB）
与 §7 的可实现读数（传感器深度 +5.5–9.0 dB）之间的差距，正是"深度源 + 静态保护"的代价，
逐项归因。**论文因此从"机制多余吗？"的质疑变成"机制解决了朴素方案做不到的两件事"的正面**
——P0-1 消解。

## 4. 诚实边界

- **L1 规模**：3 序列 × seed0（对照目的，非正式批）；R1 侧复用 L1_v4 存量（跨批 HEAD 一致）。
- **朴素臂不落 DynPortBuffer 计数**（无生命周期语义）；J5 不适用朴素臂（已标注）。

- **C1 判 False 的语义**：不是"算子无用"，而是"算子的收益不在动态区幅度、在可用性"。
