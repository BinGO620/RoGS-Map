## 判据（与 pt2 同阈值，不因序列调整）

1. **①b 天花板（M_bad，主读数）**：`P2 vs P1` 深度-L1 比值 ≤ 0.70 且 PSNR 差 ≥ +2.0 dB
2. **① 天花板（全掩码，参考）**：同上（降为参考口径）
3. **③ 无伤**：`|Δstatic_psnr(P2−P1)| ≤ 0.25 dB` 且 `Δfull ≥ −0.25 dB`
4. **④ 成本**：`mean_n_dyn ≤ 50% × n_static`
5. **⑤ 仪器**：`dyn_dl1(C−)/dyn_dl1(P2) ≥ 1.15`
6. **⑥ 阳性对照**：P1 全图 PSNR 与既有 `render_compare` 结果同帧一致（max|Δ| ≤ 0.01 dB）
7. **C1b 因果保留率（M_bad，主）**：`retention(P2c) ≥ 0.50`
8. **描述性**：P4 vs P1（"插一次冻结 ≈ 抹掉"是否复现）

## 解释规则（跑前锁定）

- 若 ①b/① 与 pt2 同向且量级相当 ⇒ **"抹掉的代价"是跨序列的**（可写进边界刻画）；
- 若 C1b 与 pt2 同向（≥0.50）而**外观侧同样低** ⇒ 因果化的"几何留得住、外观留不住"也是跨序列的；
- 若任一结论在 balloon 上**翻转**（如抹掉代价很小）⇒ 必须如实报告为**序列相关**，并说明与物体/运动特性的关系
  （balloon 是单物体、运动更简单；pt2 是人体、形变+部分可见）。
- 本批复现**不改变**已收口的 pt2 结论；它与 pt2 一起构成"跨序列"证据，但仍是**单 seed、两序列**。

## 边界
