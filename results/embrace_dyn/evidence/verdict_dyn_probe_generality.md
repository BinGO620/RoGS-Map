## 1. 判决

## 3. 三条结论

**G1（"抹掉的代价"跨序列成立，单物体刚性目标上更严重）**：以**同集比值**比较（不跨序列比 dB）——
`M_bad` 上 P2/P1 深度-L1 比值 **0.214 / 0.184**（pt2 0.565 / 0.555）；
`M_bad` 占图 8.7–9.2%（pt2 5.8%）。
⇒ 反动态范式丢弃的信息量**不是 pt2 人体场景特有**；在充气球这类**刚体、运动平滑**的目标上，
被抹掉的区域更集中、更"无处可寻"。

**G2（"几何留得住、外观留不住"两序列同向）**：因果保持的**几何**保留率
balloon 0.666–0.719 / pt2 0.583–0.590；**外观（PSNR）**保留率 balloon 0.144–0.161 / pt2 0.12–0.14。
⇒ 「KF 插入 + 保持能恢复几何占位、不能恢复像素级外观」在**两序列上同向**。
*措辞限定*：n=2 序列、单 seed ⇒ 是"跨序列同向"，**不是**"已证明跨场景稳健"。

**G3（保守机制的静态代价：**本轮**无法判定是否跨序列存在**）**：静态区 Δ
balloon −0.26 / −0.19 dB、pt2 −0.53 / −0.63 dB。**注意两点**：① ±0.25 dB 带是**母批对 P2 臂**预注册的，
**未对因果臂预注册**（此处只作参考读数）；② balloon gate 的超带余量 **0.0055 dB** 落在
母批实测 L2 噪声（≤0.012 dB）之内，且 balloon **没有自己的 L2 重复性测量** ⇒
**该序列上的"轻微损伤"在本精度下不可判定**。pt2 侧的 −0.53/−0.63 dB 远大于噪声，结论不受影响。

## 4. 局限与未做项（不得越界引用）

- **单 seed、两序列**（pt2 = 可形变人体；balloon = 刚体）⇒ 「跨序列」而非「全表」级；**未测 ATE**。
- **未做的有力对照**（审查者指出，认账）：① **同序列内受控对比**（在 pt2 内取运动最平滑的帧子集，
  分离"目标类型"与"机制极限"）；② **面积归一**（两序列 `M_bad` 占图 8.7–9.2% vs 5.8%，
  G1 已改用比值口径，但面积差仍未消除）；③ balloon 的 L2 重复性（缺失 ⇒ G3 无法判定）。
- 两序列的 SLAM commit 未逐臂 `git log` 定格（R33 同批已由批次时间戳与代码同一性记录覆盖）。
- `dynamic_mask_gtmc` 在 balloon 上的覆盖正确性未单独核（pt2 侧已核；两者同源同法）。
- 离线命令的未试便宜变体仍未试（退化帧回退 / 掩码源替换 / >2KF 最小二乘），见因果轮 II 裁决 §5。
