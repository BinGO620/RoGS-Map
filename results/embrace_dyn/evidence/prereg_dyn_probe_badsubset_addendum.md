# 预注册补遗：掩码内指标的"真损坏子集"限制（M_bad）

> **账本登记（2026-09-25 追补，D2-015 同例；原文零改动）**：本预注册属账本设立前的文书，决策留痕见 `NOTES.md` 实验清单与 git 历史；本轮由 health_check H5 扩表（`prereg_*` 纳入覆盖面）后检出为“未挂账本号”，按机制登记补入本指针，不追改正文。

**落盘时间**：2026-09-19（**在本补遗定义的两组数字被计算之前**）
**适用对象**：`prereg_dyn_probe.md`（父）与 `prereg_dyn_probe_causal.md`（因果）的**全部臂**
**动机（跑前诊断，已实测）**：GTMC 掩码面积帧间剧烈跳动（4k→116k px，最大 38% 图像），
逐帧实测"掩码内 P1（erase）渲染错误 >10cm"的像素占比为 **17.7%–98%**、合计 **55.6%**
⇒ 掩码内确有约 **44%** 的像素是 P1 本来就渲染正确的**背景**。
在这些像素上，"用被评估帧自身观测插入"（P2）等价于**把输入图像复制一遍**，其 PSNR 增益
**不是内容恢复**。⇒ 父预注册的"天花板 +10.3dB"混入了该复制项，必须分离量化。

## 定义（锁定）

**真损坏子集**：
```
M_bad(f) = dynasty_mask(f) ∧ (GT depth 有效) ∧ [ P1(f) 渲染深度无效 OR |P1渲染深度 − GT深度| > 0.10 m ]
```
- **逐帧、逐地图由 P1（erase）臂的渲染深度确定**，对**所有臂完全相同**（配对；
  P1 自身也在此子集上评分）⇒ 不会偏向任何一臂。
- `0.10 m` 阈值与父探针残影/静态指标的 10cm 量级一致；**跑前锁定**。
- `M_bad` **不含**任何结果指标（只用 P1 的几何渲染 vs GT 深度）。

## 新增指标（每帧、每臂）

`dyn_bad_px`（子集像素数）、`dyn_bad_psnr`（子集内 PSNR）、`dyn_bad_dl1_cm`（子集内惩罚式深度 L1）。

## 判据修订（两条，取代父/因果预注册中相应条目的**主读数**）

1. **天花板（修订主读数）**：在 `M_bad` 上，`P2 vs P1`：`dyn_bad_dl1` 比值 ≤ 0.70
   且 `dyn_bad_psnr` 差 ≥ +2.0 dB。**全掩码口径的数字降为参考**（须与子集口径并陈，禁止单独引用）。
2. **因果保留率（修订主读数）**：`retention_bad(X) = (dyn_bad_dl1(P1) − dyn_bad_dl1(X)) /
   (dyn_bad_dl1(P1) − dyn_bad_dl1(P2))`，`retention_bad(P2c) ≥ 0.50`。

其余判据（无伤/成本/仪器）不变——它们本就在静态区与全图口径上定义，不受本补遗影响。

## 解释规则（跑前锁定，防事后叙事）

- 若 `M_bad` 上的增益**显著小于**全掩码增益 ⇒ 差额归因于"复制已正确背景"，
  **必须如实写进结论**：父预注册的"天花板 +10.3dB"被**高估**，真实的内容恢复收益以子集口径为准。
- 若 `M_bad` 上的增益与全掩码相当 ⇒ 复制项不显著，父结论成立。
- 两种情形都要报告 `M_bad` 占掩码的比例（17.7–98%，逐帧），并说明本序列掩码的异质性。

## 边界

- `M_bad` 依赖 P1 的渲染，故它衡量的是"**反动态范式的实际错误**"，不是"物体像素"。
  这是刻意的：它把问题限定在**可测量的损害**上，避免与被掩码覆盖但渲染正确的背景混淆。
- 各臂仍共用同一轨迹/掩码/帧集合；配对性不变。
