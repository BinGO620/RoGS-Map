# 预注册：embrace_dyn 因果轮 III —— 多帧累积插入 + 逐基元速度（V2-lite）

> **账本登记（2026-09-25 追补，D2-015 同例；原文零改动）**：本预注册属账本设立前的文书，决策留痕见 `NOTES.md` 实验清单与 git 历史；本轮由 health_check H5 扩表（`prereg_*` 纳入覆盖面）后检出为“未挂账本号”，按机制登记补入本指针，不追改正文。

**落盘时间**：2026-09-19（在任何本轮臂的渲染指标被计算之前）
**动机（全部来自已落盘证据）**：
- **公平性审计**（`diag_causal_fairness.json`）显示轮 II 的 NO-GO **部分不可归因于机制**：
  在"**KF 掩码 ≥ 中位**"的帧上，因果保持的保留率升至 **几何 0.802 / 外观 0.231**（掩码小的帧仅 0.216/0.014）；
  外观保留率随 Δt 陡降（dt=1: 0.342 → dt≥3: 0.01–0.04）。**拟合预算对等**（各臂 loss 下降比 0.37–0.42）。
- **文献（`resources/lit_dyn_mapping/mechanisms.md` V2）指出我四条失败臂的共同缺陷**：
  它们全用**整团点云的全局运动估计**（质心/刚性），而 DynaGSLAM 用
  **逐基元 KNN 复用/搬移 + 逐基元速度**（`q.v=(p−q.mu_prev)/dt`，命中阈值 `λ_d·d̄`）。
- 另：我的因果臂**每次只从单个 KF 的一帧观测插入**，没有多帧累积 ⇒ 物体不完整、外观只由单视图决定。

## 1. 本轮臂（全部因果：只用帧号 ≤ t 的观测）

| 臂 | 插入观测 | 运动 | 说明 |
|---|---|---|---|
| P1 / P2 | — / 该帧自身 | — | 基线与非因果上限（沿用，作参照） |
| **P2c** | 单个 KF 的掩码 | 无 | 轮 I 主臂（**本轮控制**） |
| **P2cu** | **KF 及前 w 帧（窗 [k−w, k]）掩码点云的并集** | 无 | 隔离"多帧累积"的贡献 |
| **P2cuv**（主臂） | 同 P2cu | **逐基元 KNN 速度**：对并集中每个点，在前一帧点云里找 1-NN，若距离 ≤ λ_d·d̄ 则 v=(p−q)/Δ（否则 v=0）；渲染时 x′ = x + v·(t−k) | V2-lite：**不做全局估计**，逐点搬移 |
| C−c | 同 P2cuv | 拟合后沿相机系横移 0.30m | 主臂阴性对照 |

**锁定参数**：窗口 w = **4**（与 KF 间隔同量级）；λ_d = **0.05**（DynaGSLAM 原文值）、d̄ = 该点云到其 KNN 的平均距离；
其余（插入约定/stride=3/300 步/lr 分组/seed 0/掩码源/KF 源/冷启动规则/`M_bad` 与 `M_good` 口径/同帧集配对）**全部沿用前置预注册**。

## 2. 指标
沿用全部口径；新增逐帧：`w_used`、`n_matched_frac`（匹配上的点占比）、`v_med_m_per_frame`（逐点速度中位）。

## 3. 判据（跑前锁定；主口径 = `M_bad` 子集、同帧集配对）

1. **E1 多帧累积的单独贡献（消融）**：`dyn_bad_dl1(P2cu)/dyn_bad_dl1(P2c) ≤ 0.90`（并报外观口径）。
2. **E2 外观保留率（主判据）**：`retention_psnr(P2cuv) ≥ 0.40`
   （轮 II 主臂 0.048、轮 I 的 P2c 0.158；审计显示掩码好的帧可达 0.231 ⇒ 0.40 要求"累积+逐点速度"再翻近一倍）。
3. **E3 几何保留率**：`retention_bad(P2cuv) ≥ 0.75`（轮 II 0.583）。
4. **E4 无伤**：`|Δstatic(P2cuv−P1)| ≤ 0.25 dB` 且 `Δfull ≥ −0.25 dB`。
5. **E5 成本**：`mean_n_dyn(P2cuv) ≤ 50% × n_static`。
6. **E6 仪器**：`dyn_bad_dl1(C−c)/dyn_bad_dl1(P2cuv) ≥ 1.15`。
7. **E7 分层读数（不判，但必须报）**：按 **KF 掩码规模**与 **Δt** 分桶的保留率
   （审计已证二者是主导因子；本轮须看新臂是否把"掩码小"的桶也拉起来）。

**出局规则**：E2 ∧ E3 ∧ E4 ∧ E5 ∧ E6 ⇒ **GO**（进入核心机制实现 + 3090）；
¬E2 或 ¬E3 ⇒ **NO-GO**（此时才可主张"离线可达上限受机制限制"，且须与审计的分层读数并陈）；
其余 ⇒ PARTIAL；¬E6 ⇒ 仪器失效。E1 仅作消融。

## 4. 预期与失败模式（跑前写下）
- **预期**：多帧并集应显著提高几何保留（物体更完整）；逐点速度应改善外观（对齐更准），
  但因速度为逐点估计、无平滑，可能引入抖动 ⇒ 若 E2 过而 E4 不过，说明需加平滑/门控（记录，不就地加）。
- **若 P2cu ≈ P2c**：说明"单帧 vs 多帧观测"不是瓶颈 ⇒ 瓶颈只在掩码质量与 Δt（则下一步试掩码聚合）。
- **若 P2cuv 明显劣于 P2cu**：逐点速度需门控/平滑 ⇒ 记录为"逐点速度的朴素形式不可用"。

## 5. 边界
- 仍为离线筛选：单序列（pt2，必要时 balloon）、单 seed、两张同批地图；**未测 ATE**。
- 本轮**不**实现阈值匹配后的"搬移既有基元"（那需要跨 KF 的基元同一性，属在线实现范畴）；
  P2cuv 用"每次重新插入 + 逐点速度"近似，差异如实说明。
