## 1. 判决

**NO-GO（两地图一致）**：**多帧累积**只带来 **3%** 几何改善（E1 比值 0.969，门槛 ≤0.90 ❌；E1 是
**误差比**口径、非保留率）、外观几乎不动（21.95 vs 21.83）；**逐基元 KNN 速度**
（文献 V2 / DynaGSLAM T2 的离线近似）**反而更差**（bad_psnr 20.65 vs 21.95、bad_dl1 21.18 vs 19.56）
⇒ 外观/几何保留率双双不过（E2 ❌ E3 ❌）、静态区 −1.03 dB（E4 ❌）。成本 36% 静态基元、
仪器有效（E5 ✅ E6 ✅）。静态损伤幅度**两地图一致但不同幅**：gate −1.0303 dB、
baseline **−1.2425 dB**（`E4.d_static_db`）。
按预注册出局规则（¬E2 ∨ ¬E3 ⇒ NO-GO；E1 仅作消融）**判决成立**。

## 3. 结论

1. **运动建模在本栈上四次尝试、无一可用**（计数锚定工件，**此前写"五次"是错的**，见 §6 第 2 条）：
   ① 全局均值速度 `P2cv`（轮 I）、② 全局中位速度 `P2cm`（轮 II）、③ 刚性常扭转 `P2cr`（轮 II）、
   ④ **逐基元 KNN 速度** `P2cuv`（轮 III，文献自己的参数化）。
   **口径订正**：轮 I 的机器判决是 **PARTIAL**（主判据 C1b 几何保留 0.5936/0.6068 过阈，
   `dyn_probe_verdict.json:causal_judgments`），**不是全负**；全负的是轮 II 与轮 III。
   共同根因 = **评估是像素级对齐**（F8）：把物体整体搬走而估错的动作会**破坏原本已经对的部分**。
2. **多帧累积的读数必须分层看，且不能把两个聚合方式混用**（全部取自
   `causal3_judgments.E7_stratified`；保留率越高越好；分桶阈值 = 该地图 15 帧 `n_dyn` 的
   中位数 = **3642**，与 `diag_causal_fairness.json` 独立记录的 3642 一致）：
   - **汇总口径**（E1，`M_bad` 池化深度误差比）0.9693 ⇒ 只降 **3%** 误差，远低于 0.90 门槛；
   - **按掩码规模分桶**（`by_mask_size`，逐帧平均保留率）：P2cu 相对 P2c **几何两桶都升**
     （差桶 0.216→**0.2902**、好桶 0.8012→**0.8478**），**外观只在差桶升**
     （0.014→**0.0476**），**外观好桶是微降**（0.2311→**0.2251**）——此前写成"两桶普涨"是
     过度概括（见 §6 第 3 条）；
   - 而主臂 P2cuv **四个数全低于 P2c**：差桶 几何 0.1767 / 外观 **−0.0209**、
     好桶 几何 0.6815 / 外观 0.0659 ⇒ **叠加逐点速度把累积的增益整个吃掉**；
     **baseline 地图同向且更强**（P2c <med 0.1927→P2cu 0.2436、P2cuv 0.1518；
     ≥med 0.8059→0.8397、P2cuv 0.6632）——本轮读数以 gate 为主口径，baseline 一并列出；
   - **聚合方式警告**：E2/E3 的全集保留率与 E7 的分桶保留率**不是两种可互换的口径**。
     全集口径下 `retention_of(means)` 与 `_retention_perframe`（全帧集）**数值相同**
     （实测 gate 的 E3 两法都得 0.5021）——因为判据机的 `means` 本身就是逐帧均值；
     而把两个桶的保留率按帧数加权平均（0.4459 ≠ 0.5021）**既不等于全集口径也不等于任一桶**，
     原因是两桶的分母不同。**任何跨桶/跨口径的再平均都是错的**；
   - 跨轮对照（`diag_causal_fairness.json`，**轮 II 的 P2c**）：掩码好桶 0.8017 / 0.2313、
     差桶 0.2157 / 0.0145；拟合预算对等（loss 下降比 0.37–0.42）
     ⇒ **掩码质量与 Δt 仍是主导因子**，本轮补上的新信息 = **"补更多的点"不足以跨过它**。
3. **瓶颈指向系统级的三件事**（离线探针**难以**模拟，但并非"结构上无法"——见 §5）：
   ① **每帧插入**（而非仅 KF）；② **连续优化**（而非单帧 300 步一次性拟合）；
   ③ **掩码的时序聚合/质量**（GTMC 在部分帧近乎失效）。
   文献（DynaGSLAM：每帧 KNN 搬移 + Hermite 解析更新 + 双退役条件）在这三件事上都有机制
   （数字出处 `resources/lit_dyn_mapping/open_questions.md` 的 Q2「最省 = DynaGSLAM 的动态 GS 管理」
   成本条（当前 `:33-34`）、`papers/dynagslam.md` 的 Table 3 转录（当前 `:70`）；
   该目录由独立文献会话持续编辑 ⇒ **一律按节名引用**，行号仅作当前提示）
   —— **"必须在线实现"是推断而非本轮测量**，且 §5 列出的离线便宜变体尚未试完。
4. **边界（不越界）**：本判决针对"**离线单次插入 + 事后变换**"这一族，**不否定**在线联合优化。
   未试 V1 的时间窗门控（β/γ）与可观测性退役；其对放置精度的作用**本轮未测**，不作推断。
   **统计边界**：分桶 n=7/8、单 seed、无方差/置信区间 ⇒ §3.2 的"整个吃掉"是**观测比较**，
   不是显著性检验。
