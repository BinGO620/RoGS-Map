## 1. 本轮臂（全部因果：只用帧号 ≤ t 的数据）

| 臂 | 掩码处理 | 运动处理 | 作用 |
|---|---|---|---|
| P1 erase | — | — | 基线（沿用） |
| P2 oracle | 该帧自身掩码 | — | 非因果上限（沿用） |
| **P2c** | 原样 KF 掩码 | 无（保持） | **上轮主臂，作本轮控制** |
| **P2cs** | **KF 掩码取最大连通域（CC）** | 无 | 隔离"掩码稳定"的单独贡献 |
| **P2cm** | CC | **中位质心平移速度**（v = Δmed/(k−k_prev)，x′ = x + v·(t−k)） | 隔离"稳定掩码后的平移速度" |
| **P2cr**（**主臂**） | CC | **常扭转外推**：由两个最近 KF 的 CC 点云做 3 次 ICP（NN + Umeyama，无尺度）得相对位姿 (R,u)，按分数 frac=(t−k)/(k−k_prev) 施以 scipy 旋转向量线性插值（绕物体枢轴）+ 平移 u·frac | 完整最小机制 |
| **C−c** | CC | 同 P2cr，但**拟合后**沿相机系横移 0.30m | 主臂的阴性对照 |

**锁定项**（与前置预注册一致，不得逐臂调）：插入约定（`_gaussians_from_points`，point_size=0.01，
不透明度反 sigmoid(0.5)）、stride=3、拟合 300 步/lr 分组/seed 0、掩码源 `dynamic_mask_gtmc`、
KF 清单源（consolelog）、冷启动规则（无前置 KF 的帧不计入）、两张同批地图、同帧集配对。

**新增定义**：
- `CC(M)` = 掩码的二值连通域中**面积最大者**（scipy.ndimage.label，4/8 邻接默认）。
- 刚性外推 = 绕 B 云质心（枢轴）旋转 `rotvec(R_rel) × frac` 并平移 `u × frac`；
  `frac = (t − k)/(k − k_prev)`（KF 间隔变化时按帧数比例，不假设恒为 5）。

## 2. 指标

沿用全部口径（`dyn_psnr/dyn_dl1/dyn_bad_*/dyn_good_*/dyn_cov/full_psnr/static_psnr/ghost_excess/n_dyn`）。
新增逐帧记录：`mask_cc_frac`（CC 面积 / 原掩码面积）、`frac`（外推分数）、`icp_rmse_m`（ICP 残差）、
`n_dyn`（与前轮对比可见 F5 的缓解程度）。

## 3. 判据（跑前锁定）

1. **D1 掩码稳定的单独贡献**：`dyn_bad_dl1(P2cs) / dyn_bad_dl1(P2c) ≤ 0.95`（CC 至少买 5%）。
2. **D2 外观保留率（本轮主判据）**：在 `M_bad` 上
   `retention_psnr(P2cr) = (bad_psnr(P2cr) − bad_psnr(P1)) / (bad_psnr(P2) − bad_psnr(P1)) ≥ 0.40`
   （上轮 P2c 约 0.14 ⇒ 要求**翻近三倍**；不设更高阈值，因 oracle 用被评估帧自身观测）。
3. **D3 几何保留率**：`retention_bad(P2cr) ≥ 0.75`（用 `dyn_bad_dl1` 定义，同补遗）。
4. **D4 无伤**：`|Δstatic_psnr(P2cr − P1)| ≤ 0.25 dB`（上轮 P2c 为 −0.53/−0.63 ⇒ 运动修正**应当**改善它）
   且 `Δfull_psnr ≥ −0.25 dB`。
5. **D5 成本**：`mean_n_dyn(P2cr) ≤ 50% × n_static`。
6. **D6 仪器**：`dyn_bad_dl1(C−c)/dyn_bad_dl1(P2cr) ≥ 1.15`。

**出局规则**：D2 ∧ D3 ∧ D4 ∧ D5 ∧ D6 ⇒ **GO**（进入核心机制实现 + 3090 批）；
¬D2 或 ¬D3 ⇒ **NO-GO**（离线可达上限已尽，机制不值得上在线系统）；
其余 ⇒ **PARTIAL**（写清缺哪一条）；¬D6 ⇒ 仪器失效，不得下结论。
D1 为**消融读数**（不阻断 GO）：若 CC 无贡献，则机制简化为"仅运动"。

## 4. 预期与失败模式（跑前写下）

- **预期**：CC 单独应小幅改善（F5：小碎片掩码被剔除）；刚性外推应显著提升外观保留率（F2 的 14% → 40%+）。
- **若 D2/D3 仍不过**：说明"两 KF 之间的外推"不足（人可能非刚性运动/掩码质量仍差）⇒ 记录为
  "离线最小机制已到边界"，下一步只能上**在线联合优化**（那条路要动核心代码与 ATE，另立项）。
- **若 P2cm ≈ P2cr**：说明纯平移已够，机制可更简单（记录，不追求复杂）。
- **若 `icp_rmse_m` 大（>5cm）**：说明两个 KF 的掩码点云并不可刚性对齐（部分可见/形变）⇒ 记录并解释。

## 5. 边界（不得越界引用）

- 仍是**离线筛选**：单序列、单 seed、两张同批地图（同序列同 seed，非独立复现）；**未测 ATE**。
- 因果性仍受"KF 时刻的观测质量"限制（本轮只改善掩码与运动，不改善 KF 调度——那是核心实现的事）。
- `M_bad/M_good` 口径与可比性规则（同集比值、dB 跨集不可比）沿用补遗。
