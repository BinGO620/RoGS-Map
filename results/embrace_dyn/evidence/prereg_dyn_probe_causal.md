## 1. 问题

父探针的 P2 臂用**被评估帧自身**的观测插入动态基元 ⇒ 是**非因果的构造性上限**，
不是任何在线系统能做到的。真实系统只能：**在关键帧（KF）插入**、**在任意帧渲染**，
且插入只能用「帧号 ≤ 当前帧」的数据。

**问题**：因果化之后还剩多少收益？速度外推（最小时序模型）是否有增量？

**已知条件（跑前实测）**：该 run 的 KF 间隔**恒为 5 帧**（consolelog 的
`Candidate insert KF <n>`，n=113 个：5,10,…,565）；16 个锁定评估帧中，
**除 f=2（冷启动）外，最近前置 KF 的时差 Δt 仅为 1–4 帧**。

## 2. 因果协议（锁定；每臂只许用下列数据）

| 臂 | 允许使用的数据 | 定义 |
|---|---|---|
| **P1 erase** | — | 冻结地图原样渲染（父预注册同义臂） |
| **P2 oracle** | 被评估帧自身观测 | 非因果参照（父预注册同义臂，仅作上限对比） |
| **P2c 因果-保持** | 帧号 ≤ t 的位姿；插入只用 KF k = max{KF ≤ t} 的掩码+深度+RGB | 在 k 插入 + 局部拟合（拟合用 **k 自身**的观测，合法：系统当时看到了它），渲染在 t |
| **P2cv 因果-保持+速度外推**（**主臂**） | 同上 + KF k 与**上一个 KF k_prev** 的掩码点云 | 用两帧掩码点云的世界系质心差估速度 v=(c_k−c_{k_prev})/(k−k_prev)，渲染时把物体整体平移 v·(t−k) |
| **C−c 阴性对照** | 同 P2c | P2c 的物体沿**相机系横轴**平移 0.30 m（拟合后施加） |

**共同锁定项**（与父预注册一致）：插入沿用仓库自身约定（`_gaussians_from_points`，
`point_size=0.01`、不透明度反 sigmoid(0.5)）；掩码像素 stride=3；拟合 300 步、
学习率分组 `xyz 5e-4 / log_scale 5e-3 / rot 1e-3 / opa 5e-2 / dc 5e-3`、种子 0；
掩码 = `dynamic_mask_gtmc`；地图 = 同批 `gate` 与 `baseline` 两张（鲁棒性）。

**冷启动规则**：无前置 KF 的评估帧（本序列 = f2）**不进入因果判据**，
单独报告为"因果不可用（无观测）"；该规则在跑前锁定（不因结果调整）。

**KF 清单来源**：该 run 的 consolelog `Candidate insert KF (\d+)`（确定性解析；
PLY 不落盘 KF 字段，故无第二来源——**此为已知证据限制**）。

## 3. 指标（同父预注册 §6，另加因果专列）

`dyn_psnr` / **`dyn_dl1_cm`（主判据）** / `dyn_cov` / `full_psnr` / `static_psnr` /
`ghost_excess_cm` / `n_dyn`；因果专列：`kf`（插入帧）、`dt_eval = t − k`、`dt_kf = k − k_prev`、
`v_norm`（估出的速度模，m/帧）。

## 4. 判据（跑前锁定）

设 `retention = (dyn_dl1(P1) − dyn_dl1(X)) / (dyn_dl1(P1) − dyn_dl1(P2))`（X = 待评臂）。

1. **C1 因果保留率（主判据）**：`retention(P2cv) ≥ 0.50`
   —— 即因果化后仍留住 oracle 深度收益的**至少一半**。
2. **C2 速度项增益**：`dyn_dl1(P2cv) / dyn_dl1(P2c) ≤ 0.90`（速度外推至少买 10%）。
   **不达标不阻断 GO**（只说明机制可简化为"保持"），但作为消融结论如实记录。
3. **C3 无伤**：`|Δstatic_psnr(P2cv − P1)| ≤ 0.25 dB` 且 `Δfull_psnr ≥ −0.25 dB`
   （另以 P2c 复核，两臂都须满足）。
4. **C4 成本**：`mean_n_dyn(P2cv) ≤ 50% × n_static`。
5. **C5 仪器有效**：`dyn_dl1(C−c) / dyn_dl1(P2c) ≥ 1.15`（因果臂自己的阴性对照）。

**出局规则**：
- C1 ∧ C3 ∧ C4 ∧ C5 ⇒ **GO**：进入**核心机制实现**（代码保护例外流程①-⑤）+ 3090 正式批。
- ¬C1 ⇒ **NO-GO**：因果性吃掉收益 ⇒ 父预注册的天花板在线不可达；
  如实记负结果，并写清"改善路径已穷尽"的证据（本探针即为该证据）。
- ¬C5 ⇒ 仪器失效，先修工具，不得据此下方向结论。

## 5. 边界（不得越界引用）

- 本探针**仍不能测 ATE**（离线渲染）；ATE 只在核心机制实现后于在线系统中测量
  （DISCIPLINE #7：绝对 ATE 是第一验收标准，**不劣化**才谈贡献）。
- 单序列（pt2）、单 seed、两张同批地图；KF 清单单源（consolelog）。
- 渲染仍用 run 的估计轨迹（在线可得），故位姿误差进入绝对指标——但**所有臂共用同一轨迹**，
  配对差分即隔离动态内容贡献。

## 6. 预期与失败模式（跑前写下，防事后叙事）

- **预期**：Δt 仅 1–4 帧 ⇒ P2c 应已明显优于 P1；P2cv 应优于 P2c（步行速度下 1–4 帧的位移
  约 10–20 cm，正是速度项能吃掉的量）。
- **若 P2c 就已≈P2**：说明 KF 间隔足够密、速度项不必需 ⇒ 机制 = "KF 插入 + 保持"，实现更简单。
- **若 P2cv 明显劣于 P2c**：说明质心速度估计在部分可见/掩码抖动下不稳 ⇒ 记录为
  "最小速度估计器不可用"，下一步改刚性配准（不在此探针内偷偷换）。
