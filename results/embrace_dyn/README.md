## 结论（四条）

1. **天花板存在且很大**：把动态物体"建出来"能把掩码内 PSNR 从 20.8→31.1 dB、
   掩码内深度误差从 18.7→10.8 cm，**连全图 PSNR 也 +2.1~2.3 dB**（掩码支撑面积 = 10.4% 图像），
   代价是 4–6% 的基元增量。
2. **运动建模是必需的**（本次最有价值的一条）：**插一次就冻结 ≈ 抹掉**
   （P4 vs P1：掩码内 PSNR −0.46/−0.67 dB、深度-L1 比值 1.00/1.03）⇒ 朴素"保留动态"不比抹掉好；
   只有带运动/生命周期的机制才吃到收益。*成本注记*：P4 用 11,906 个基元（P2 均值的 3.37×，
   **未配平**）⇒ 其静态区损伤（−1.17/−1.10 dB）**方向可信、幅度待配平后重测**。
3. **代价是"内容错"而非"内容缺"**：掩码内覆盖率各臂**恒 1.000**（冻结地图的动态区被背景高斯覆盖、
   无洞）⇒ 反动态范式在该区渲染的是**错误背景内容**。这同时说明 `dyn_cov` 在本设定下**无判别力**，
   已登记为无判别力列，不再进任何结论。
4. **结构可行性**：冻结地图里"可形变的动态料"极少（挡在 GT 表面之前的残影候选：
   gate 1/82.9/335、baseline 2/157.2/1016（min/mean/max），最大占地图 0.61%/1.21%）⇒
   最小形式必须是**从观测新建**（P2 式），**不是**形变地图里已有的高斯。

## 因果批（第二轮，2026-09-19 晚）

**问题**：母批的 P2 天花板用**被评估帧自身**的观测插入（非因果）。真实系统只能在关键帧（KF）插入。
该 run 的 KF 间隔**恒为 5 帧**（consolelog `Candidate insert KF`，113 个），16 个评估帧里
除冷启动 f2 外最近前置 KF 只差 **1–4 帧**。

| 臂 | 定义 |
|---|---|
| P2c | **因果-保持**：只用最近前置 KF（≤ t）的掩码+深度+RGB 插入并拟合，渲染在 t |
| P2cv | 因果 + **质心速度外推**（用 KF 与上一 KF 的掩码点云质心差估速，平移 v·(t−k)） |
| C−c | 因果臂自己的阴性对照（拟合后沿相机系横移 0.30m） |

**结果（gate / baseline；因果臂为同帧集 n=15，冷启动 f2 不计入）**：
- **因果保留率（真损坏子集 M_bad，主判据）= 0.594 / 0.607**（阈值 0.50 ✅）
  （全掩码口径参考值：P2c 0.590 / 0.583；**按预注册字面把主臂定为 P2cv 时为 0.157 / 0.191 ⇒ NO-GO**，
  两种读法并陈见裁决书 §1）
- **但 PSNR 侧保留率仅约 14%** ⇒ 深度指标奖励"大致正确深度上的内容"，PSNR 要求精确对齐
  （Δt 1–4 帧 ≈ 位移 10–20cm）⇒ 目前恢复的是**几何占位，不是渲染质量**
- **静态区 −0.53 / −0.63 dB（判据 C3 ❌）**：陈旧基元停在人已离开的位置 ⇒ **鬼影重现**
  ⇒ **退役/可见性（或运动模型）是机制的必需部分**
- **质心速度估计器被证伪**（C2 比值 1.23/1.22，用了更差）：实测分布 **0.0092–0.347 m/帧**，
  按**实测帧率 29.83 Hz**（rgb.txt 时间戳，非标称值）= **0.27–10.4 m/s**（中位 3.54）
  ⇒ 跨两个数量级、**不稳定不可用**；根因 = GTMC 掩码面积在相邻 KF 间跳动 4k→116k px，质心随掩码形状漂移
- **F5（新）**：P2c 每帧插入基元数 **123 / 3,642(中位) / 12,906**（相差 100×）——
  f309 的最近 KF=305 恰落在掩码极小帧（4,051px）⇒ 只插 438 个 ⇒ 该帧几乎等于不插入
  ⇒ **掩码稳定性与插入规则同等重要**
- 机器判决：**PARTIAL**（C1b PASS / C3 FAIL / C2 FAIL）；关卡① 第 2 轮已过（§7 整改表）

**真损坏子集分解（同轮）**：掩码内 **55.8%（gate）/ 55.5%（baseline）** 是"P1 渲染真的错了（>10cm）"
（`M_bad`，均值 17,747px = 图像 5.8%），其余 ~44% 是 P1 本就正确的背景（`M_good`，14,078px）。
**只有同集比值可比**：`M_bad` 上 P2/P1 深度-L1 比值 **0.565/0.555**、PSNR 20.3→31.2；
`M_good` 上 PSNR 22.0→30.9 但**深度比值 1.19/1.09（略降）**⇒ P2 的深度收益**全部来自 M_bad**，
`M_good` 上的增益是"复制该帧自身输入"。**50cm 惩罚常数在 M_bad 上从未生效**（洞=0px，已实测）。

**下一轮（按依赖顺序，均需新预注册）**：① 鲁棒刚性配准运动臂（替代质心差）；
② 退役/可见性规则（修静态区代价）；二者过后才进核心机制实现 + 3090 正式批（+ATE 回报）。

### 局限（母批口径，前三轮共用）

- **P2 是构造性乐观上限、且非因果**：基元由被评估帧自身的掩码+深度生成 ⇒ 不是可部署数字；
  真实机制受①在线掩码质量（离线用冻结 gtmc，与在线 MaskRCNN 的差异**未量化**）、
  ②因果性（不能用当前帧观测填当前帧）、③在线优化预算 三重约束。
- **未测 ATE**（DISCIPLINE #7 绝对 ATE 是第一验收标准）：动态基元进入在线损失/BA 后对轨迹的影响
  **完全未知**；机制实现后若 ATE 劣化，本判决不构成贡献。
- **单序列（pt2）、单 seed、两张同批地图**（同序列同 seed ⇒ **不是独立复现**，只作臂间鲁棒性）；
  未测效率（探针不训练）。
- 掩码内深度-L1 用 3DGS 的期望深度，半透明基元会把背景深度混进来
  （这既是拟合必须提高不透明度的原因，也意味着该指标对不透明度敏感）。
- 拟合"生效"证据仅首末两点（P2 逐帧 0.113→0.027、opa 0.50→0.758；P4 单次 0.140→0.029、opa 0.711），
  **无 loss 曲线**；插入的深度有效区间（dmin=0.2/dmax=8.0 默认）原未入预注册，已补登。
- 残影盘点为每 25 帧抽 1 帧（23 帧），与评估 16 帧几乎不重叠 ⇒ 区间代表性有限。
- **预注册文本缺陷**：判据③原写双侧 `|Δstatic| ≤ 0.25 dB`，实测为正向 +0.12 dB（通过）；
  若为负向应读作"不劣化 ≤0.25 dB"。已如实记录，不追溯改判。

E6 仪器 1.2475 / 1.2546（≥1.15 ✅）⇒ **两地图 NO-GO**（预注册出局规则：¬E2 ∨ ¬E3 ⇒ NO-GO）。

**本轮最硬的三条读法**（分桶阈值 = 15 帧 `n_dyn` 中位数 **3642**）：
1. **叠加逐点速度把累积的增益整个吃掉**：按掩码规模分桶（`E7_stratified.by_mask_size`，逐帧平均保留率），
   P2cu 相对 P2c **几何两桶都升**（差桶 0.216→**0.2902**、好桶 0.8012→**0.8478**），
   **外观只在差桶升**（0.014→**0.0476**），**外观好桶是微降**（0.2311→**0.2251**，
   此前写成"两桶普涨"属过度概括，已订正）；而 P2cuv **四个数全低于 P2c**
   （差桶 几何 0.1767 / 外观 **−0.0209**；好桶 几何 0.6815 / 外观 0.0659）。
   baseline 地图同向且更强（P2c <med 0.1927→P2cu 0.2436、P2cuv 0.1518；
   ≥med 0.8059→0.8397、P2cuv 0.6632）。
   **聚合警告**：全集口径的 E2/E3 与分桶口径**不可互换**——全集上 `retention_of(means)` 与
   `_retention_perframe` 数值相同（E3 两法皆 0.5021），把两桶按帧数加权平均（0.4459）是错的。
2. **"补更多的点"不足以跨过掩码质量**：并集把插入基元数从 3,909 拉到 20,048（**5.13×**，
   `mean n_dyn` 比值 20048.2/3909.07），**汇总口径**（E1 池化 `M_bad` 深度**误差比**，非保留率）
   只降 **3%**。
3. **运动建模四次尝试、无一可用**：全局均值（轮 I P2cv）、全局中位（轮 II P2cm）、
   刚性常扭转（轮 II P2cr）、**逐基元 KNN**（轮 III P2cuv，文献自己的参数化）。
   共同根因 = F8：评估是**像素级对齐**，把物体整体搬走而估错会**破坏原本已对的部分**。
   （**口径订正**：轮 I 的机器判决是 **PARTIAL**——主判据 C1b 几何保留 0.5936/0.6068 过阈——
   不是全负；"五次"的计数也是错的，运动变体实为 4 个 + 累积变体 1 个。）

**边界**：本判决针对"**离线单次插入 + 事后变换**"这一族，**不否定**在线联合优化。
**未试的便宜离线变体**（不声称穷尽）：预注册 §4 自己写下的"逐点速度门控/平滑"（条件已触发但未执行）、
退化帧回退、>2 KF 最小二乘、按 Δt 分档、非连通域掩码稳定化、换掩码源/序列。
故"离线已到边界"改为"**继续在离线加机制的边际收益预期低**（判断）"。
统计边界：分桶 n=7/8、单 seed、无方差/CI ⇒ 上述"吃掉"是观测比较，非显著性检验。
仍未测 ATE、单序列单 seed、两张同批地图。
